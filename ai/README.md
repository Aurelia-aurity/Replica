# AI

학교 GPU에서 실행할 LLM 추론과 개인화 코드를 관리합니다.

- `src/`: 추론·말투 프로필·RAG 등 서비스 코드
- `tests/`: AI 코드 테스트
- `configs/`: 공유 가능한 모델·추론·개인화 설정
- `.env.example`: 비밀 값이 없는 설정 예시

현재는 골격만 있습니다. 모델, Python·CUDA 버전, 의존성, 실행·테스트 방법은 초기 구현 시 기록합니다.
모델 가중치, 체크포인트, 개인 기록, 로컬 검색 색인은 커밋하지 않습니다.
비교·평가 실행은 `../experiments/`, 백엔드 연동 형식은 `../contracts/`에서 관리합니다.
