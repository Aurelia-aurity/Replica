# 학교 GPU AI API 운영·접속 조건 확인 결과

기록일: 2026-10-13 · 관련 이슈: [#14](https://github.com/Aurelia-aurity/Replica/issues/14)

학교 회신과 현재 관측을 정리했습니다. 회신은 추론 구성 가능성을 안내했으며,
외부 PC에서 SSH 경유 테스트 HTTP 응답도 확인했습니다. AWS에서의 호출과 실제 LLM
API는 아직 검증하지 않았습니다. 공식 연결 방식과 서비스 운영 조건도 일부 미확인입니다.

## 문의와 근거

김태환은 2026-10-12 학교 담당 창구에 메일로 문의했습니다. 질문은 학교 GPU 작업에서
AI API를 실행하고 AWS 백엔드가 호출해도 되는지, 허용 기간·프로토콜·포트·접속 범위와
권장 연결 방법·추가 이용 규칙이 있는지였습니다. 2026-10-13 김일경 교수의 회신을 받았습니다.

| 회신 요지 | 확인 범위 | 남은 조건 |
| --- | --- | --- |
| 포트 10000을 이용한 추론 가능 | 해당 포트 이용 가능 안내 | 회신에서 SSH와 HTTP를 구분하지 않음 |
| 고정 IP 사용 | 서버 주소 운영에 대한 안내 | GPU 재할당 후 주소·접속 경로 유지 여부 미확인 |
| Admin 계정이 필요 없는 구성은 자체 설치 가능 | 관리자 권한 없이 설치하는 구성 안내 | 상시 운영·자동 재실행·자원 및 데이터 이용 조건 미확인 |

회신은 추론 서비스 구성을 안내한 근거입니다. 특정 SSH 터널 방식이나 AWS 연결을
명시적으로 승인한 문구로 확대 해석하지 않습니다. 메일 원문은 문의 담당자가 보관하며,
이 문서에는 개인 연락처·메일 주소·서버 계정·실제 접속 주소를 넣지 않습니다.

## 접속과 GPU 작업 관측

아래 결과는 2026-10-13 관측입니다. 직접 검사와 사용자가 실행해 전달한 결과를 구분했습니다.

| 확인 | 결과 | 수행·근거 | 한계 |
| --- | --- | --- | --- |
| 로그인 서버 외부 10000번 프로토콜 | SSH 배너 확인 | 도구에서 단일 포트 접속 | HTTP 추론 포트가 아님 |
| 로그인 서버 → GPU 계산 노드 | SSH 경유 접속에서 DIS02 출력 | 사용자 실행 결과 | AWS 출발 경로는 아님 |
| 계산 노드 외부 10000번 직접 접속 | 검사 환경에서 타임아웃 | 도구에서 단일 포트 접속 | 모든 환경에서 차단된다는 증거는 아님 |
| GPU 할당 | DIS02, RTX A6000, 49140 MiB | 사용자 hostname·nvidia-smi 출력 | 해당 시점의 할당 결과 |
| Python | 3.12.7 | 사용자 실행 결과 | 전체 의존성·모델 실행 검증은 아님 |
| 테스트 HTTP | 200, 고정 JSON 응답 | 사용자 curl 출력 | 합성 응답이며 LLM 추론 없음 |

테스트 HTTP는 GPU 노드의 loopback에만 실행했고, 사용자 PC의 loopback 포트와
SSH 경유로 연결했습니다. 파일 제공이나 개인 데이터 처리는 하지 않았습니다.
사용자는 시험 후 서버와 터널을 종료했다고 보고했습니다.

```text
사용자 PC → 로그인 서버 SSH → GPU 계산 노드 SSH
         → 계산 노드 localhost 테스트 HTTP → 사용자 PC에 HTTP 200
```

이 시험은 사용자가 별도로 요청한 접속 조사에서 얻은 참고 관측입니다.
#14에 제외된 임의 터널 구성을 공식 운영 방식이나 필수 산출물로 편입하지 않습니다.
이 PR은 운영 설정·터널 코드·외부 API 공개를 추가하지 않습니다.

## Slurm 시간과 종료

사용자가 로그인 노드에서 실행한 결과입니다.

```text
sinfo -p p02 -o "%P %l"
PARTITION TIMELIMIT
p02* 7-00:00:00

squeue -u "$USER" -o "%.18i %.8T %.12M %.12l %.20N"
JOBID STATE   TIME TIME_LIMIT NODELIST
18867 RUNNING 8:06 30:00      DIS02
```

`p02`의 표시된 최대 시간은 7일입니다. 시험 작업은 30분으로 요청했고,
위 출력 시점에 8분 6초 경과했습니다. 테스트 서버와 터널을 종료한 뒤에도 GPU 작업은
RUNNING이었습니다. 서버 프로세스 종료와 자원 할당 종료는 별개입니다.

7일은 파티션 상한입니다. 계정별 제한·자원 가용성이나 실제 7일 운영 성공을 확인한 것은
아닙니다. 할당 만료 후 자동 재할당·모델 재로드·재접속 동작도 검증하지 않았습니다.

## 미확인 조건과 후속 담당

| 항목 | 현재 상태 | 후속 담당·처리 |

| 서비스 인증·키 관리·접속 범위 | 미합의 | #15 합의와 AWS 연동 이슈에서 구성 결정; 미확정 상태로 외부 공개 금지 |
| 상시 실행·유휴 작업·자동 재할당·동시 할당 규칙 | 미확인 | 김태환이 현행 안내 또는 학교 창구로 확인; 자동화는 후속 범위 |
| 재할당 후 노드·주소·저장 위치 | 미확인 | API 작업에서 수동 재준비 절차 확인, 저장 영향은 임재성과 검토 |
| 프로젝트 종료 후 사용 기간 | 미확인 | 김태환이 이용 종료 전에 학교 조건 확인 |
| 개인 기록·로그·다운로드·저장 규칙 | 미확인 | 김태환·임재성 확인 전 합성 자료로 한정 |

추가 답변이 없는 항목은 허용으로 간주하지 않습니다. 현행 이용 안내나 담당자 확인으로
보완하고, 확인되지 않은 조건에 의존하는 외부 운영은 보류합니다. 학교 GPU의 외부 운영
조건이 충족되지 않으면 AWS Mock 또는 허용된 로컬 시연을 유지하고 팀과 일정 영향을 검토합니다.
