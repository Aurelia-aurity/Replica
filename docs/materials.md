# 자료 보관과 원본

개발·협업 과정은 GitHub에 남기고, 수업 자료와 제출용 파일은 [팀 Drive](https://drive.google.com/drive/folders/1mWkROL5Lj1PcriPdHs3MBy--TSxXpOhg)에 보관합니다. [Notion 허브](https://app.notion.com/p/3ee54b33957f808f879fc8b85e37e5bc)는 자료를 찾는 진입점과 공지·일정 운영 공간입니다.

| 자료 | 원본·갱신 위치 |
| --- | --- |
| 코드, 팀 개발·설계 문서, 기술 결정, 회의록, 협업·AI 활용 기록 | GitHub. 이슈·작업 브랜치·PR로 갱신 |
| OT·AI-Factory 등 수업·기업 제공 자료, LMS·카카오톡 공지 원문 | Drive. 제공 범위와 공유 권한 유지 |
| 수행계획서·보고서·발표 파일, 제출 증빙 | Drive. 제출본과 초안을 구분 |
| 팀·멘토 회의 전사문·녹취 | Drive. GitHub에는 정리한 회의록·결정만 기록 |
| 요약·문서 링크, 운영 공지·일정 | Notion. 원문과 출처 링크를 함께 안내 |

새 버전을 보관할 때 날짜·초안/최종/제출본을 식별하고, 기존 제출본을 보존합니다. 최종본이 바뀌면 이 문서와 Notion 링크도 함께 갱신합니다.

## 접근과 제출

팀원 전원의 GitHub·Notion 접근과 편집, Drive 접근은 사용자 확인을 받았습니다. 연결 도구에서도 Drive 폴더·파일 목록 조회를 확인했습니다. 팀원별 계정에서 에이전트가 직접 시험한 결과는 아닙니다. 새 팀원에게 필요한 권한을 부여하고 전체 공개를 보관의 전제로 삼지 않습니다.

Drive 보관은 LMS·산학플랫폼 제출을 대신하지 않습니다. 발표 파일은 수업 안내에 따라 LMS에도 제출하고, 보고서는 해당 공지의 제출 방법을 따릅니다. 제출 결과는 증빙 폴더와 관련 이슈에 기록합니다.

OT에는 수행 과정·결과물을 GitHub에 남기라는 포괄적인 안내가 있습니다. 원본 파일 대신 자료 링크와 수행 기록을 남기는 방식이 평가 요건을 충족하는지는 아직 확인되지 않았습니다.
