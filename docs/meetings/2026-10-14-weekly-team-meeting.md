# 2026년 10월 14일 팀 미팅 요약

회의일: 2026.10.14

## 회의 핵심

각 파트의 개발 현황을 공유하고 API·DB·화면 간 연동 기준을 논의했다. 우선 과제는 API 명세를 실제 데이터 구조와 사용자 흐름에 맞추고, 기록 입력부터 개인화 반영·대화까지 기본 기능을 연결하는 것이다.

## 주요 결정 및 개발 방향

| 항목 | 정리 내용 |
| --- | --- |
| 단계별 개발 | 고도화 기능까지 API 명세에 반영하되, 실제 구현은 기본 기능부터 단계별로 진행한다. |
| 대화 방식 | 텍스트 대화와 음성 대화를 별도 세션으로 구분한다. 텍스트 화면의 음성 입력은 우선순위를 낮춘다. |
| 기록 처리 | 기록 업로드 → 전사 → 사용자 확인·수정 → 개인화 반영의 흐름으로 구성한다. |
| 오류 대응 | 타임아웃 및 원인 불명(unknown) 오류에서도 재시도를 허용하는 방향으로 합의했다. |

## 파트별 진행 현황

프론트엔드: 홈 화면·채팅 연결 구현 및 PR 제출. 로그인·회원가입 화면 작성 완료, 연결과 기록 업로드 화면 개발 예정.

AI: 기본 실행·평가 진행. AWS와 학교 GPU 연결 확인 중이며, API 합의 후 연동 구현 예정.

백엔드·DB: 서버·외부 연결 시험과 테이블·함수 작업 진행. API 초안을 공동 검토하고 데이터 구조에 맞춰 보완해야 한다.

## 우선 후속 과제

① 프론트·백엔드·AI·DB가 API 초안을 공동 검토하고 누락 필드와 기능을 보완한다.

② 사용자·페르소나 식별 정보, 대화 이력 정책, 대상 화자와 처리 상태 전달 규칙을 정한다.

③ 개인화 방식과 “반영 완료” 기준을 확정하고 기본 흐름의 통합 동작을 검증한다.

④ 멘토님께 논문 작성·표기 및 기업 명의 앱 출시 조건을 확인하고 미팅 일정을 조율한다.

## 일정 및 유의 사항

11월 2일 발표를 목표로 기본 기능 구현을 시도하고, 11월 중순 논문 제출에 대비한다. 시험 일정으로 개발 여유가 부족하므로 기본 기능 완성을 우선해야 한다.
