# 2026년 11월 1일 팀 미팅 요약

회의일 2026.11.01

## 회의 핵심

프론트엔드·AI·DB의 연결 명세를 확정하고, 실제 서비스 통합 및 검증을 우선 진행한다.

멘토링·발표·논문 준비를 병행하며, 구독 서비스와 API 예산은 사용량과 정산 조건을 확인한 뒤 조정한다.

## 1. 개발 현황 및 협업 방향

로그인·회원가입 화면, 기록·채팅·삭제 기능, 대화 처리 흐름과 DB 통신 작업이 진행됐다. AI는 모델 6개 비교 후 8B급 모델을 조건부 선택하고, 프롬프트 개선과 RAG 구현을 진행했다. 실제 백엔드 연결·통합 검증은 남아 있다.

통신 명세와 인증·데이터 전달 경로를 PR에서 신속히 확정한다. 팀원은 하루 한 번 리뷰 대상을 확인하고, 통합 중 막히는 문제는 주간회의를 기다리지 않고 즉시 공유하기로 했다.

## 3. 우선 실행 과제

① 연결 명세 확정·PR 정리: 프론트엔드·AI·DB 연동 경로를 합의하고 미처리 PR의 차단 요인을 해소한다.

② 통합 실행·품질 검증: 실제 대화 흐름을 끝까지 점검하고, 개인화·계정 격리·삭제 반영·텍스트 및 음성 중단 처리를 검증한다. 프롬프트 개선과 LoRA 적용을 병행한다.

③ 방문·행정·발표 준비: 식당·교통편을 확정하고 승인·정산 조건을 확인한다. 발표 자료 검토와 멘토링 사전 점검을 완료한다.
