# 2026년 10월 2일 멘토 미팅 회의록

## 주요 논의

멘토는 화면 기획서를 먼저 작성해 주요 화면과 기능, 최종 결과물의 모습을 구체화할 것을 권했다. 화면 기획서 초안은 일주일 안에 준비하고 AI 도구로 만든 HTML이나 화면 이미지도 활용할 수 있다고 했다.

10월 12일 중간 발표에서는 전체 기능 통합을 서두르기보다 화면 기획서, 시스템 구성도, ERD·테이블 정의서와 각 파트의 진행 상황을 보여주도록 조언했다. 시스템 구성도에는 AWS 아이콘을 활용하는 방법도 제안했다.

음성 API는 ElevenLabs를 중심으로 많아야 2~3곳을 비교하고 AI는 학교 GPU에서 경량 모델을 실행하며 LoRA와 RAG 적용을 시도해보도록 권했다. Flutter 기반 Android 앱에서 카카오톡 대화 내보내기를 바로 받을 수 있도록 연결하는 방안도 제안했다.

DB는 소규모 시연에 맞춰 정규화한 구조부터 설계하고 반정규화는 우선 진행하지 않는 방향을 권했다. 테이블을 설계할 때는 데이터 정합성과 중복 방지를 중요하게 고려한다.

## 후속 작업

- 주요 화면과 기능을 담은 화면 기획서 초안을 준비한다.
- 시스템 구성도와 ERD·테이블 정의서를 정리한다.
- 매주 회의에서 진행 상황·어려움·다음 작업을 공유하고 회의 뒤 카카오톡에 100글자 이내 요약을 올린다.
- 오프라인 멘토링은 중간고사 이후인 11월 첫째 주를 후보로 잡고 일정을 조율한다.
- 멘토링 보고서 제출 시 멘토에게도 메일 참조로 공유한다.

오프라인 일정과 세부 구현 방식은 아직 확정하지 않았다.
