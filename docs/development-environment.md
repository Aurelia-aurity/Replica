# 개발 환경

팀이 합의한 개발 도구를 기록합니다. 이 문서는 실제 설치 확인 결과나 실행 가이드가 아닙니다. 실행 명령과 의존성 파일은 각 파트 구현 시 해당 README에 추가합니다.

| 도구 | 합의한 기준 | 추가 확인 |
| --- | --- | --- |
| Flutter | 3.47.5, 앱 개발에 사용. Android 우선 | 팀원별 실제 설치 상태 |
| Android Studio | Amul, Android 에뮬레이터 실행·구동 테스트에 사용 | 세부 빌드·Android SDK·에뮬레이터 구성 |
| Python | 3.12 계열 | 패치 버전 |
| FastAPI | 0.142.1 | 팀원별 실제 설치 상태 |
| Docker | AWS 배포 전 로컬 확인에 사용 | 버전 |
| Supabase | Docker 기반 로컬 사용 후 배포 검토 | CLI·로컬 구성 버전 |

앱은 Flutter로 개발하고, Android Studio에서 실행한 Android 에뮬레이터로 구동 환경을 테스트합니다.

위 버전 문자열은 사용자 제공 합의 값입니다. 설치 가능 여부나 호환성을 이번 문서 작업에서 검증한 것으로 보지 않습니다. 변경이 필요하면 관련 파트와 합의하고 이 문서를 PR로 갱신합니다.

AI 활용 기록과 개인 로컬 문서 관리 기준은 [AI 활용](ai-usage.md), 역할과 리뷰 절차는 [협업 안내](../CONTRIBUTING.md)를 참고합니다.
