# 프로젝트 일정과 공지 기준

[최종 수행계획서](materials.md)의 개발 간트는 계획의 기준입니다. 운영 일정은 [Notion 캘린더·간트·마일스톤](https://app.notion.com/p/3ee54b33957f808f879fc8b85e37e5bc)에서 관리하며 최신 수업·AI위밋 공지를 함께 확인합니다. 아래 날짜는 모두 2026년, 시각은 한국 시간입니다.

## 정기 팀 미팅

팀 미팅은 **매주 수요일 저녁**에 진행합니다. 이슈별 진행 상황·어려움·다음 작업을 공유하고, 회의 후 결정 사항과 담당·후속 작업을 회의록에 남깁니다. 구체적인 시작 시각과 일정 변경은 팀에서 별도로 공유합니다.

## 발표·팀 일정

| 일정 | 날짜·시각 | 기준·준비 |
| --- | --- | --- |
| 각 파트 진행 상황·자료 공유 | 10/9 저녁 | 10/7 팀 회의. 모든 기능·PR 완료 마감은 아님 |
| 수업 중간 발표 | 10/12 | 멘토·팀 회의. 임재성 발표 준비·발표·LMS 발표자 등록 |
| 다음 정기 팀 미팅 | 10/14 수요일 저녁, 시작 시각 미정 | 매주 수요일 저녁 진행 합의 |
| AI위밋 발표·중간점검 및 중간보고서 제출 | **11/2 18:00**, 강의실 | 최신 카카오톡 공지. 보고서는 당일 현장 제출 |

AI위밋 발표와 중간점검은 같은 행사입니다. 계획서의 이전 발표·보고서 날짜 대신 위 공지로 운영하고, 동일 행사 참고 행을 별도 발표로 집계하지 않습니다. 정기 팀 미팅은 위 주간 기준을 따르며, 오프라인 멘토링 시각은 별도 조율합니다.

## AI위밋 필수 보고서·지원비

| 항목 | 공지 날짜·방법 |
| --- | --- |
| 지원비 사용 계획서 | 9/28. 지원금 사용 전 서식1 제출 필수 |
| 재료비·구독비 신청서 | 9/30까지 |
| 1차 멘토링 보고서 | 10/2, 산학플랫폼 업로드 |
| 중간보고서 | 11/2 18:00 중간점검 당일 현장 제출 |
| 2차 멘토링 보고서 | 11/6, 산학플랫폼 업로드 |
| 3차 멘토링 보고서 | 12/4, 산학플랫폼 업로드 |
| 결과보고서·발표자료 | 12/11, 산학플랫폼 업로드 |

지원비는 팀당 100만원이며 재료비·구독비 결제일은 매월 2일입니다. 승인된 팀은 결제 후 3일 이내 증빙을 담당자에게 메일 제출합니다. 신청·승인·제출·결제 완료 여부와 결제 대상 월은 아직 확인되지 않았습니다.

최소 2회 오프라인 멘토링이 필요합니다. 보고서의 컨소시엄명은 `인공지능`, 담당교원은 교과목 담당 교수로 작성합니다. 학회참가비 지원에 따른 사사문구와 담당자 연락처는 Notion의 AI위밋 공지·제출 안내 및 Drive 공지 원문에서 확인합니다.

## 갱신 기준

새 공지가 오면 원문을 Drive에 보관하고, 변경된 일정·제출 방법을 Notion과 이 문서에 반영합니다. 기준이 된 공지와 변경 이유를 이슈·PR에 남깁니다. 예정일이 지났다는 이유만으로 제출 완료를 표시하지 않습니다. 제출용 파일 보관과 실제 제출은 [자료 안내](materials.md)에 따라 구분합니다.
