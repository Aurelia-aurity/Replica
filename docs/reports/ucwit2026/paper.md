# 사용자 확정 기록 기반 개인화 대화 시스템의 근거성 향상 설계와 평가
Design and Evaluation of Grounding Improvements for a Personalized Dialogue System Based on User-Confirmed Records

## 요약
본 연구는 사용자가 확인한 기록을 사실 근거로 삼는 한국어 개인화 대화 시스템을 설계하고 평가했다. 기록 질의응답, 지시 이행 및 한국어 이해를 비교해 Qwen3-8B를 서비스 모델로 선정한 뒤 세 프롬프트 조건과 두 검색 조건을 비교했다. 평가에는 연구팀이 구성한 한국어 합성 기록·질문을 사용했다. 기본 지시·청크 검색과 결합 프롬프트(근거 제한+말투 지시)·원기록 문맥 복원 검색의 전체 구성 비교에서 핵심 정답률은 60.8%에서 90.8%로 높아졌고 사실 날조율은 36.7%에서 7.9%로 낮아졌으나, 말높임 일치율은 43.3%로 하락했다. 결합 프롬프트·청크 검색 구성도 비교했지만 근거 비움과 문맥 복원 각각의 효과는 분리하지 않았다. 청크 검색에서 결합 프롬프트는 근거 제한 단독보다 말높임 일치율이 높았고 사실 날조율도 높았다. 답 없음 48문항에서 두 검색 방식 모두 근거를 비우지 않았지만, 두 근거 제한 조건은 모두 답변을 유보했다. 최종 구성의 일상 대화 정답은 2/24, 사실 날조는 19/24로 일상 대화 처리에 한계를 보였다.

## 1. 서론
개인 기록으로 특정 인물의 대화를 재현할 때 그럴듯하지만 틀린 정보는 대상자에 대한 기억과 이용자의 경험에 영향을 줄 수 있다 [1]. 일상 대화에는 생략과 문맥 의존이 많아 청크만 검색하면 사건의 연결이나 화자를 놓칠 수 있다. 이때 질문 속 거짓 전제나 기록에 없는 정보가 답변에 섞일 수도 있다.

본 연구는 사용자가 확인한 전사문과 화자를 사실 근거로 삼고 사실 판단과 말투 반영을 분리한다. 모델 선정 뒤 근거 제한과 말투를 결합한 프롬프트를 적용하고 유사도 임계값에 따른 근거 비움과 원기록 문맥 복원을 설계했다. 한국어 합성 기록 평가로 프롬프트 조건과 검색 조건의 결과 및 질문 유형별 차이를 비교한다.

## 2. 관련연구
Generative Ghosts는 고인에 관한 그럴듯한 허위 정보가 기억과 유족에게 초래할 수 있는 위험을 다룬다 [1]. RoleFact는 허구 인물의 지식 경계 밖 응답을 줄이기 위해 검색과 원자적 사실 검증을 결합한다 [2]. 본 연구는 공개 대본 대신 사용자가 확인한 개인 기록을 사실 근거로 사용한다.

LongMemEval은 사용자–어시스턴트 대화 이력의 장기 기억과 답변 유보를 평가하며 거짓 전제 질문도 포함한다 [3]. 본 연구는 한국어 페르소나 기록에서 근거 비움을 평가한다. CREPE는 공개 지식 질의응답에서 거짓 전제를 탐지하고 바로잡는다 [4]. 본 연구의 근거 범위는 개인 확정 기록이다. SeCom은 주제 단위 기억과 압축 기반 검색 잡음 제거를 제안한다 [5]. 본 연구는 토큰 예산에 맞춰 검색 청크 주변의 원기록 문맥을 복원한다. KoBEST는 다섯 한국어 이해·추론 과제로 일반 언어 능력을 평가한다 [6]. 본 연구는 KoBEST를 기록 질의응답과 함께 모델 선정에 사용해 일반 한국어 능력과 기록 근거성을 구분한다.

## 3. 시스템 설계 및 구현

### 3.1 근거성 향상 설계
기록 밖 사실 생성과 거짓 전제 수용을 줄이도록 프롬프트와 검색의 근거 구성을 설계했다. 기본 지시는 간결한 한국어 답변을, 근거 제한 지시는 기록 밖 사실 생성을 억제하고 거짓 전제를 교정하도록 요구한다. 개발 중 기록에 정답이 있을 때 직접 답하도록 강조한 후보는 근거성과 거짓 전제 대응이 나빠져 채택하지 않았다. 최종 결합 프롬프트에는 근거 제한과 페르소나 말투 제어를 함께 두었다. 청크 검색은 유사도 상위 5개 청크를 전달한다. 원기록 문맥 복원 검색(이하 문맥 복원 검색)은 질문별 최고 유사도가 기준에 못 미치면 근거를 비운다. 기준을 통과하면 상위 3개 청크를 시작점으로 주변 원기록 문맥을 복원한다. 복원 범위의 중복을 합치고 2,000토큰 예산을 적용하므로 최종 근거 청크는 3개를 넘을 수 있다. 그림 1에 두 검색 방식의 근거 구성과 공통 답변 생성을, 4.2절에 구체적인 검색 설정을 제시했다.

### 3.2 앱
Flutter 기반 Android·iOS 앱은 Supabase Auth로 로그인·가입을 처리하고, DB 테이블에는 직접 접근하지 않도록 설계했다. 이용 동의와 화자·제공자 선택을 거쳐 전사문을 확인·수정하도록 했다. 대화에서는 AI 생성 표시와 근거 파일명·날짜·발췌문 및 합성 음성 안내를 제공하도록 했다. 기록 삭제 시 연관 자료와 프로필 반영분도 함께 제거하도록 했다.

로그인·회원가입, 텍스트·음성 대화, 이력 조회, 기록 관리 UI를 구현하고 더미 인증으로 앱 기능을 확인했다.

### 3.3 백엔드
FastAPI 백엔드는 Supabase Auth의 Bearer JWT에서 사용자 ID를 확인하며, 본문 ID는 권한 근거로 쓰지 않도록 설계했다. 대화는 turn_id별 STT·AI·TTS 단계로 처리하고 최근 대화 20쌍을 AI에 전달하도록 했다. 재전송 시 완료 단계를 재사용하며, 단계별 실행권으로 중복 처리와 늦은 결과를 막도록 설계했다. 응답 음성은 저장하지 않고, TTS 실패 시 텍스트를 유지하며 AI 생성 표시를 제공하도록 했다.

FastAPI는 대화방 생성, 텍스트·음성 대화와 답변 TTS API를 제공한다. AI는 고정 응답 Mock과 계약 기반 원격 호출을, STT·TTS는 Mock을 지원한다. 백엔드 시험은 모의 DB·AI를 사용했다.

### 3.4 데이터베이스
Supabase PostgreSQL에서는 대화방·턴·기록·텍스트 버전·말투 프로필·검색 청크를 대화 상대별로 연결한다. 확정 텍스트의 수정 이력과 프로필 원본 개정 번호를 관리한다. 텍스트 버전·검색 청크에는 사용자·대화 상대 범위를 검사하는 복합 외래 키를, 조회에는 RLS를 적용하고 쓰기 권한은 백엔드에서 확인한다. 검색 대상은 동의된 현재 확정본으로 한정한다.

원격 Supabase에 스키마를 적용하고 Python 접근 함수를 반영했다. 합성 자료와 임시 계정 2개로 저장·조회, 계정 분리, 일반 사용자 토큰의 직접 쓰기 및 서버 전용 함수 호출 차단, 턴 실행권과 이전 시도 결과 거부, 확정본 검색과 삭제 요청 기록 제외를 확인했다.

구성요소별 구현 확인과 별도로, 4절에서는 3.1절의 프롬프트·검색 구성을 오프라인으로 평가한다.

## 4. 실험 설계 및 평가

### 4.1 평가 데이터
평가에는 연구팀이 구성한 한국어 합성 기록·질문을 사용했다. 실제 개인 기록은 개인정보 문제로 제외하고 사실 날조와 거짓 전제 수용이 드러나도록 질문 유형을 나누었다. 데이터는 가상 페르소나 6명, 기록 240건(일기 120건·대화 120건), 질문 240개로 구성한다. 질문 유형은 단일 기록 사실, 다중 기록 추론, 거짓 전제, 모호성, 답 없음, 일상 대화이며 유형별 문항 수는 표 1과 같다. 목표 말투는 하게체·해요체·반말이고 말투별로 80문항씩이다. 사실 질문에는 필수 사실 요소와 허용 별칭을 정했다.

표 1. 평가 데이터셋 구성

| 질문 유형 | 문항 수 |
|---|---:|
| 단일 기록 사실 | 48 |
| 다중 기록 추론 | 48 |
| 거짓 전제 | 48 |

| 일상 대화 | 24 |

최초 후보 모델 비교(표 2)에는 기록 질의응답 20문항과 지시 이행 20문항, KoBEST 다섯 과제를 사용했다. 추가 모델 비교에서는 6개 후보별로 기록 질의응답·지시 이행·근거성 문항을 각각 120개씩 적용했다. 별도의 단계별 프롬프트·검색 비교에는 위 합성 데이터 240문항을 사용했다.

### 4.2 실험 설정 및 평가 방법
평가 기준과 판정 절차는 실행 전에 고정했다.

모델 비교 후보는 단일 48GB GPU에서 구동할 수 있는 8B 이하 Apache-2.0 공개 모델 6종으로 정했다. 여기에는 기존 기준 모델 Qwen2.5-7B-Instruct, Qwen3 계열, 국내 기업이 공개한 한국어 모델 A.X와 Kanana를 포함했다. 기록 질의응답 성공은 유효한 JSON을 출력하고 모든 정답 슬롯을 충족했을 때로 판정했다. 기록 질의응답과 지시 충족의 최고값에서 각각 5%p 이내인 후보를 남긴 뒤, 그중 KoBEST가 가장 높은 모델을 택했다. 작성자 1인이 자연스러움·지시 준수·적절성/유용성·근거 없는 개인 사실 방지의 네 영역을 점검했다. 이 네 영역의 동일 가중 평균이 기준 모델 Qwen2.5-7B-Instruct의 4.34점보다 0.5점 이상 낮으면 제외하거나 보류하는 보조 기준도 두었다. Qwen3-8B의 평균은 4.01점으로 이 기준에 해당하지 않았다. 표 2의 근거성(1–5점)은 이 탐색적 점검의 한 영역이며 단독 제외 기준은 아니었다. 추가 근거성 평가는 규칙 검사와 자동 판정(LLM 기반)으로 산출했으며, 두 평가의 점수 증감을 직접 비교하지 않았다.

Qwen3-8B를 고정하고 기본 지시, 근거 제한 단독, 결합 프롬프트의 세 조건을 청크 검색에서 비교했다. 기본 조건에도 공통 말투 지시가 포함됐다. 근거 제한 단독은 결합 프롬프트에서 근거와 말투의 우선순위 문장, 관계·호칭·말높임 지시와 목표 말높임 정보를 제외했다. 정체성·근거·질문 정보는 유지했다. 이미 결과를 확인한 240문항에 추가한 조건으로, 새로운 독립 검증은 아니다. 기본 조건과의 차이는 근거 제한만의 효과가 아니며, 결합 프롬프트와의 차이도 말투 제어 묶음 전체의 비교다. 결합 프롬프트에는 문맥 복원 검색과 정답 근거 입력(진단용)을 적용해 총 다섯 조건을 평가했다.

각 질문·조건은 한 번 생성했다. 공통 생성에는 탐욕적 디코딩을 적용하고 최대 출력을 160토큰으로 제한했다. 문맥 복원 검색은 KURE-v1 임베딩의 L2 정규화 코사인 유사도를 사용한다. 질문과 청크 간 최고 유사도가 0.5459 미만이면 근거를 비운다. 0.5459 이상이면 상위 3개 청크를 문맥 복원의 시작점으로 사용한다. 대화 기록은 앞뒤 3턴을, 일기는 전문을 복원한다. 개별 기록의 복원 문맥이 토큰 한도를 넘으면 해당 검색 청크로 대체한다. 전체 예산이 초과되면 낮은 점수의 기록부터 제외해 근거 JSON을 Qwen3-8B 토크나이저 기준 2,000토큰 이내로 맞춘다.

검색 설정은 별도의 개발 질문 40개에서 고정했다. 설정 당시 과거 비교에서 원본 코퍼스 상위 5개 청크의 필수 근거 포함률은 66.7%였고 인코더 비교의 상위 5개 결과 포함률은 KURE-v1 80.0%, multilingual-e5-small 53.3%였다. 이 값들은 현재 평가 결과가 아니라 설정을 정할 때 참고한 과거 비교다.

검색은 사실 질문의 필수 슬롯·별칭 포함률과 답 없음 질문 유형의 근거 비움 비율로 평가했다. 응답은 규칙 검사와 대규모 언어 모델 기반 자동 판정으로 채점하고 위험·불확실 응답은 재판정했다. 기본 지시·결합 프롬프트의 두 검색 조건과 정답 근거 조건에서는 통과 응답의 25%(올림)를 조건·질문 유형·하게체 여부로 층화 추출해 재판정했다. 불일치율 5.88%가 사전 기준을 넘어 전체 응답을 재판정했으며 근거 제한 단독 조건도 전체 응답을 재판정했다. 일상 대화에서 질문을 그대로 반복한 응답은 정답으로 세지 않았고 말투와 종결어미는 따로 검사했다. 핵심 정답은 필수 사실 포함, 사건 구분, 거짓 전제 정정, 답 없음의 적절한 답변 유보, 일상 대화의 적절한 응답으로 판정했다. 기록 밖 개인 사실을 추가하면 사실 날조로, 전달된 근거로 답할 수 있는 질문을 거절하면 과잉 거절로 분류했다.

필수 사실 완전 포함률은 단일 기록 사실·다중 기록 추론·거짓 전제 각 48문항과 모호성 24문항을 합한 사실 질문 168문항을 분모로 삼았다. 핵심 정답률·사실 날조율·말높임 일치율은 전체 240문항, 거짓 전제 정정률·안전한 답변 유보율은 해당 유형 48문항을 분모로 계산했다.

### 4.3 평가 결과 및 논의
표 2는 최초 후보 모델 6종의 결과다. 기록 질의응답과 지시 이행의 최고값에서 각각 5%p 이내인 후보 가운데 KoBEST가 가장 높은 Qwen3-8B를 선정했다. 기준 미달 후보를 먼저, 선정 모델을 마지막 행에 배치했다.

표 2. 후보 모델 비교

표 3은 같은 240문항에서 세 프롬프트 조건을 비교한다. 근거 제한 단독 조건의 핵심 정답률은 기본 지시보다 6.7%p 높고 사실 날조율은 11.3%p 낮았지만 거짓 전제 정정률은 6.3%p 낮았다. 답 없음 질문 유형의 안전한 답변 유보율은 기본 조건의 54.2%에서 두 근거 제한 조건 모두 100%로 높았다. 결합 프롬프트는 근거 제한 단독 조건보다 핵심 정답률이 2.1%p, 거짓 전제 정정률이 10.4%p, 말높임 일치율이 32.9%p 높았다. 사실 날조율도 5.0%p 높았다. 세 프롬프트 조건의 과잉 거절은 모두 0%였다.

목표 말높임을 입력하지 않은 근거 제한 단독 조건의 19.6%는 평가상 목표와 출력의 관찰 일치율이다. 조건 간 차이는 제어 묶음 전체의 비교이며, 말투 지시 이행 능력이나 개별 지시의 독립 효과를 뜻하지 않는다.

## 5. 결론
본 연구는 사용자 확정 기록 기반 한국어 개인화 대화 시스템의 근거성을 높이기 위해 프롬프트와 검색 구성을 설계하고 조건별로 평가했다. 합성 기록·질문 평가에서 근거 제한 단독 조건은 기본 지시보다 핵심 정답률이 높고 사실 날조율이 낮았으나, 거짓 전제 정정률은 낮았다. 관계·호칭·말높임 지시와 목표 말높임 정보를 포함한 결합 프롬프트에서는 근거 제한 단독보다 말높임 일치율과 거짓 전제 정정률이 높았고 사실 날조율도 높았다. 문맥 복원 검색 조건은 청크 검색보다 핵심 정답률이 높고 사실 날조율이 낮았으며 말높임 일치율은 낮았다. 답 없음 문항 48개에서 검색 단계의 근거 비움은 없었지만 결합 프롬프트는 모두 답변을 유보했다. 최종 구성의 일상 대화 정답은 2/24(8.3%), 사실 날조는 19/24(79.2%), 말높임 일치율은 43.3%였다. 검색 요소별 효과와 일상 대화 사실 날조 및 말투 저하의 원인은 확인하지 못했다. 후속 연구에서는 검색 근거 비움, 일상 대화 생성, 말투 제어를 개선하고 통합 환경에서 성능을 평가한다.
