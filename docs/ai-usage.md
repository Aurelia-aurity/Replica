# AI 활용과 검증 기록

PR에는 AI 활용 범위와 작성자가 검토·확인한 내용을 간단히 남깁니다. AI와 대화하며 설계·구현·수정을 이어가는 바이브코딩도 PR 단위로 정리합니다.

## 공통 기준

- AI가 만든 코드·문서의 책임은 작성자에게 있습니다. 반영한 내용을 이해하고 작업에 맞는 분석·수정·검증을 진행합니다.
- PR 템플릿의 AI 활용·검증 항목을 사용합니다. PR 없는 조사·실험은 이슈에 같은 내용을 적습니다.
- 사용하지 않은 작업은 `사용하지 않음`으로 적습니다. 사용 모델·버전·환경은 확인한 값만 적고 추측하지 않습니다.
- 비밀값, 개인 대화·녹음, 공유 권한 없는 자료를 기록에 넣지 않습니다. 전체 프롬프트·대화 복사는 요구하지 않습니다.
- AI 활용을 위한 개인 로컬 설정·지침·작업 기록·인수인계 문서는 Git으로 관리하지 않습니다. 파일명과 관계없이 개인 용도인지로 판단합니다. 팀이 공유하기로 한 공통 지침과 프로젝트 산출물은 Git에서 관리합니다.
- 개인 문서의 경로는 `.git/info/exclude` 또는 개인 Git ignore에 등록합니다. 팀에서 공통으로 사용하는 개인 파일 경로는 `.gitignore`에 반영할 수 있습니다. 파일명만으로 모든 AI 관련 문서를 일괄 제외하지 않습니다.

## PR 기록 예시

아래는 형식 예시이며 실제 수행 결과가 아닙니다.

- AI 활용 범위: Codex와 대화하며 협업 규칙을 구체화하고 문서·PR 템플릿을 작성·수정함.
- 검토·확인: 팀 합의와 문서 표현을 검토하고 문서 링크·파일 제외 규칙을 확인함.

프롬프트마다 기록하거나 AI가 작성한 줄을 구분할 필요는 없습니다. 상세 실행·테스트 결과는 PR의 검증 항목을 참조하고, 확인하지 못한 내용은 그곳에 남깁니다. PR 없는 작업은 이슈에 같은 두 항목을 적습니다.
