# #38 구현 상태

Cloudflare Workers Free + D1 권한 설계는 승인됐습니다. 이 디렉터리는 구현 중인 후보이며, 아직 배포할 수락본이 아닙니다. 실제 계정·App 설치·비밀키 등록·배포·활성화는 하지 않았습니다. 설정의 D1 ID는 자리표시자이며 기본 모드는 `STOPPED`입니다.

현재 구현한 범위는 서명된 helper 예약·단일 변경 허가·안전 취소·결과 기록, Notion 원문 서명 검증·의미 단위 중복 수신 기록, 공개키로 암호화하는 초기 검증 토큰 보관, 최신 페이지 결속 확인, 일반 Actions 실행 요청·일회용 claim, 전체 실행 관측과 chunk/seal, 로컬 agent helper입니다. 미확정 작업의 예약은 자동으로 해제하지 않습니다. HTTP 성공은 수신 기록을 뜻하며 Project 변경이나 Notion 반영을 증명하지 않습니다.

로컬 Node 검사 64개와 전체 Python 검사 462개가 통과했습니다. Worker 최종 검토에서 확인된 최신 조회 실패, seal/chunk 경합, 저장소 장애 재전송, fenced 결과 사용 문제 4건은 수정 후 독립 재검토에서 종결됐습니다. 저장소 장애 복구 시에는 하나의 SQL 조회로 기존 결과와 충돌 여부를 함께 확인합니다. 로컬 Miniflare/D1에서는 일회용 claim, 23행의 chunk/seal, 별도 실행 완료 확인, 키 분리, 실제 Python helper의 7가지 정상·실패·재시작 경로를 확인했습니다. 경합 순서를 강제하는 검사는 SQLite 기반 LocalD1에서 실행했습니다. 해당 검사에서는 합성 ID와 가짜 키만 사용했습니다. 실제 Worker Free CPU·Notion 웹훅·GitHub App 권한·서비스 반영은 검증하지 않았습니다.

동기화 엔진과 helper의 최종 검토를 마친 뒤 Draft PR을 열어 두고 대기합니다. #39와 독립된 브랜치이며 별도로 적용할 수 있습니다. 실제 구성은 별도 human-check 대상입니다. 기존 5분 전체 동기화와 PM 재개 경로는 그대로 남아 있습니다. 필수 검사와 최종 리뷰가 끝나기 전에는 커밋·푸시·배포·운영 완료로 처리하지 않습니다. 배포 순서와 복구 명령은 [README](README.md)에 정리했습니다.

운영 한도는 미삭제 helper 작업 1,000개와 Notion 수신 19,000개입니다. helper 결과를 남길 공간을 예약하며 새 작업을 거절할 때 기존 기록을 삭제하거나 유료 플랜으로 전환하지 않습니다. 실제 운영 용량·Free 사용량은 배포 전 확인 대상입니다.

이벤트가 최신 상태를 포함하지 않으므로 후속 API 조회가 필요하며, 재전송의 원문 서명은 매번 확인합니다. 형식은 [Notion 공식 이벤트 문서](https://developers.notion.com/reference/webhooks-events-delivery)를 기준으로 구현했습니다.
