# Experiments

모델 선정, 개인화 단계, STT·TTS 품질과 지연 시간 비교를 관리합니다.

- `configs/`: 평가 실행 설정
- `results/`: 공유 가능한 지표, 표, 분석 결과

결과에는 실행 날짜, 코드 커밋, 모델·설정, 평가 데이터 버전·출처, 측정 방법을 함께 기록합니다.
개인 발화·대화·전사문·생성 응답 등 민감한 원문은 결과 파일에도 넣지 않습니다.
가중치·체크포인트·대용량 산출물은 Git 밖에서 관리하고 준비 방법만 문서화합니다.

## 현 LLM baseline 평가 (#33)

실행·채점 안내: [baseline/README.md](baseline/README.md).
확정한 합성 질문 20개로 현재 모델의 기준값을 먼저 측정합니다.
실제 개인 자료를 입력하지 않습니다. 합성 질문에서 생성한 답변도 공개 전에 개인정보와 민감한 내용을 확인합니다.

첫 실측 결과: [2026-10-10 Qwen2.5-7B-Instruct 평가](results/2026-10-10-qwen2.5-7b-baseline/README.md).
학교 GPU 본 평가 60회와 사용자 채점 20문항을 완료했으며, 사용자 점수와 보조 분석을 구분해 기록했습니다.
