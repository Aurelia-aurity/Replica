# Experiments

모델 선정, 개인화 단계, STT·TTS 품질과 지연 시간 비교를 관리합니다.

- `configs/`: 평가 실행 설정
- `results/`: 공유 가능한 지표, 표, 분석 결과

결과에는 실행 날짜, 코드 커밋, 모델·설정, 평가 데이터 버전·출처, 측정 방법을 함께 기록합니다.
개인 발화·대화·전사문·생성 응답 등 민감한 원문은 결과 파일에도 넣지 않습니다.
가중치·체크포인트·대용량 산출물은 Git 밖에서 관리하고 준비 방법만 문서화합니다.

## 현 LLM baseline 평가 (#33)

실행·채점 안내: [baseline/README.md](baseline/README.md).
확정한 합성 질문 20개로 현재 모델의 기준값을 먼저 측정합니다.
실제 개인 자료를 입력하지 않습니다. 합성 질문에서 생성한 답변도 공개 전에 개인정보와 민감한 내용을 확인합니다.

첫 실측 결과: [2026-10-10 Qwen2.5-7B-Instruct 평가](results/2026-10-10-qwen2.5-7b-baseline/README.md).
학교 GPU 본 평가 60회와 사용자 채점 20문항을 완료했으며, 사용자 점수와 보조 분석을 구분해 기록했습니다.

## 평가 지표 확장 (#36)

실행·채점 안내: [evaluation/README.md](evaluation/README.md).
사람의 의미 판단, JSON QA·지시 준수의 기계 채점, KoBEST와 운영 지표를 구분합니다.
확정한 합성 문항을 사용하며 기존 #33 결과를 보존합니다.
실측 결과: [2026-10-13 Qwen2.5-7B-Instruct 평가](results/2026-10-13-qwen2.5-7b-evaluation/README.md).
학교 GPU 생성 180회와 KoBEST 4,561문항을 완료했습니다. 사용자 전체 점수, AI가 작성하고 사용자 결정을 반영한 의미 판정, 기계 점수를 별도로 기록했습니다.

## 화자 귀속 단일 변경(O3) DEV 실험 (#100)

실측 결과: [2026-11-10 화자 귀속(O3) DEV 실험 결과](results/2026-11-10-issue100-speaker-attribution/README.md).
동결 기준·코드·합성 데이터: [experiments/stage1-100/README.md](stage1-100/README.md).
합성 `DEV-v3` 1,320문항(3,960응답)에서 기준선(`B`), `O3` 단일 변경(`A`), 정답 페르소나 진단군(`C`)을 비교했습니다. 주 지표는 통과했으나 근거성·핵심 사실 정답·안전한 답 보류 비열등성을 통과하지 못해 서비스 채택 승인이 없고(2026-11-25 담당자 미채택 확정), 별도 1회 후속 확인(`confirm-v3`)은 채점 중단으로 미결론으로 기록했습니다.

## 서버 워밍업·구간별 지연 (#96)

실행·분석 안내: [warmup_timing/README.md](warmup_timing/README.md).
준비 완료 전 합성 워밍업 동작, 워밍업 전후 첫 요청 지연, 구간별 처리 시간과 TTFT, 동시 요청 1/2/4건 응답 지연을 측정합니다.
실제 개인 발화나 대화 원문은 사용하지 않으며 합성 요청만 기록합니다.
실측 결과: [2026-11-14 Qwen3-8B 워밍업·구간별 지연 측정](results/2026-11-14-issue96-warmup-timing/README.md).
학교 GPU 작업 55389·55817에서 각 851건 요청을 완료했으며, 워밍업 전후 비교, TTFT, 구간별 시간, 동시성별 성공 지연과 미측정 범위를 함께 기록했습니다.
