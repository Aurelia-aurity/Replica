# Qwen2.5 7B Instruct 전체 평가

평가 대상은 Qwen2.5-7B-Instruct이며 학교 GPU에서 생성한 답변과 KoBEST 결과를 평가했다. 실행일은 2026-10-13, 사람 평가 반영일은 2026-10-14다. 이번 결과는 #36의 기존 모델 기준선으로 사용한다.

## 평가 결론

사람 평가 평균은 3.80/5점이다. 기본 질문, 표현을 바꾼 질문, 기록을 바꾼 질문에는 대체로 높은 점수를 받았지만 잘못된 전제에 동의하도록 요구하는 유도 질문에서는 5개 중 4개가 1점이었다. 기록에 맞는 정보를 답하는 능력과 사용자의 잘못된 주장에 저항하는 능력 사이에 차이가 나타났다.

기계 평가에서는 JSON 형식 준수율이 100%였지만 기록 QA의 전체 정답률은 50%였다. 지시 준수 평가의 전체 조건 충족률은 75%이며 단일 조건은 91.67%, 복합 조건은 50%였다. KoBEST 5개 과제의 정확도 단순 평균은 67.54%였다. 서로 다른 능력을 측정하는 지표이므로 하나의 종합 점수로 합치지 않는다.

현재 모델의 후속 비교에 사용할 기준선은 확보했다. 개인 기록에 관한 답변에는 유도 질문 대응, 알 수 없는 정보 처리, 한국어 유지와 대화 표현의 보완이 필요하다. 다른 모델보다 우수한지, 서비스에 적용할 수준인지는 이번 평가만으로 확정하지 않는다.

## 생성 성능 관측

세 생성 과제 모두 본 실행 60회씩 EOS로 종료했다. 실패·빈 답변·출력 상한 종료·미실행은 각각 0회다. 각 과제의 준비 실행은 3회이며 상한 종료가 없어 320토큰 보충 실행은 없었다.

| 생성 과제 | 성공한 본 실행 | 평균 생성 시간 | 호출별 tokens/s의 평균 |
|---|---:|---:|---:|
| 사람 평가용 답변 | 60 | 1.067초 | 32.70 |
| 기록 QA | 60 | 0.597초 | 31.85 |
| 지시 준수 | 60 | 1.093초 | 32.54 |

생성 시간은 GPU 동기화를 포함한 모델의 생성 구간이다. 모델 로딩, 네트워크, 화면 표시까지의 시간은 포함하지 않는다. 출력 길이가 다른 과제이므로 시간 차이를 품질이나 모델 간 속도 우열로 해석하지 않는다. TTFT와 서비스 전체 응답 시간은 측정하지 않았다.

| 생성 과제 | 최대 peak allocated (bytes) | 최대 peak reserved (bytes) |
|---|---:|---:|
| 사람 평가용 답변 | 15,261,286,912 | 15,290,335,232 |
| 기록 QA | 15,282,290,688 | 15,315,501,056 |
| 지시 준수 | 15,260,656,128 | 15,290,335,232 |

메모리는 성공한 본 생성 호출 중 PyTorch allocator의 최댓값이다. 적재 후 resident 값은 통합 보고서에 별도로 남겼으며 위 값에 다른 프로세스나 CUDA context의 전체 메모리를 포함했다고 해석하지 않는다.

## 결과의 적용 범위와 후속 작업

사람 평가는 한 평가자의 20문항 결과이며 평가자는 대상 모델과 앞선 결과를 알고 있었다. 모델명을 숨긴 독립 평가로 해석하지 않는다. 네 질문 유형은 같은 5개 기록에서 파생됐고 기록 QA도 같은 내용을 재사용한다. 3회 반복도 독립된 새 문항 60개를 의미하지 않는다. 이번 결과를 전체 한국어 대화나 모든 개인 기록 상황의 성공률로 일반화하지 않는다.

기본 정보 회수와 형식 준수는 후속 모델 비교에서 유지할 기준으로 삼는다. 유도 질문에 대한 기록 우선 응답, 미기록 정보를 추정하지 않는 응답, 한국어 유지, 자연스러운 확인 질문은 비교·개선 시 집중해서 볼 항목이다. 이를 어떤 학습이나 설정으로 해결할지는 개선 전후 평가로 확인해야 한다.

사용자 전체 점수20개, 새20문항의 세부 의미 판정과6개 지표·문항 쌍 집계, 기존 #33의5문항 소급 판정 및 기계 평가 결과를 모두 기록했다. 평가 항목의 미확정 건은 없다. 이 디렉터리에 결과와 실행 근거를 반영했다. #36의 이슈 종료와 병합은 PR 검토 이후 별도로 처리한다. #37에서는 확정된 입력·설정·채점 규칙을 다른 모델에도 동일하게 적용해 비교한다.

## 도입 및 보류한 평가

고정 형식 기록 QA의 Exact Match, 문자 규칙으로 검사하는 지시 준수, KoBEST 5개 전체 test를 채택했다. 자유 답변의 의미 판단과 자연스러움을 이 기계 점수에 섞지 않는다. 공식 IFEval 전체를 도입한 것은 아니며 여기서는 합의한 한국어 규칙 20문항을 사용했다. KMMLU는 이번 개인 기록·지시 준수 기준선의 범위를 넘어서는 지식 평가이므로 보류했다. 여러 벤치마크의 평균을 서비스 합격 기준으로 사용하지 않는다.

실행 전에 고정한 `scoring-contract.json`에는 새 문항의 블라인드 평가 계획이 남아 있다. 실제 평가는 모델을 아는 상태에서 진행했으므로 계획과 다른 점으로 기록한다. 실행 입력이나 원래 점수를 소급해서 고치지 않았다. 기존 #33의 네 영역별 평가를 유지하고 이번 확장 20개 전체 점수와 AI 보조 의미 판정은 별도 축으로 남긴다.

## 출처와 미측정 항목

실제 실행은 사용자가 학교 GPU에서 수행했다. 로컬에서는 전달받은 원본 로그와 결과를 다시 검증·집계했다. 추출 번들에는 Git 저장소가 없어 실행 commit은 `null`이며 코드·입력·모델 파일 SHA-256으로 연결한다. 모델의 upstream revision은 검증되지 않았다. 드라이버 525.105.17은 사용자 실행 로그에서 확인했으며 자동 수집 필드는 `null`이다. 실제 package inventory는 KoBEST identity에 보존했지만 별도 `pip freeze` 파일은 전달받지 않았다.

PyTorch allocator의 생성 중 peak allocated/reserved와 적재 후 resident 메모리는 통합 보고서의 각 `operational`에 있다. 이는 전체 GPU VRAM 사용량이 아니다. TTFT, 네트워크를 포함한 전체 응답 시간, 전체 GPU VRAM은 미측정이다. 본 실행의 출력 상한 종료, 빈 답변, 실패와 미실행 개수는 각 원본·통합 보고서에서 구분한다. 보충 답변과 준비 실행은 점수·운영 평균에서 제외한다.

공개한 생성 답변은 고정된 가상 인물 기록으로 만든 합성 자료이며 실제 개인 기록·발화는 포함하지 않는다. KoBEST 원본 약 10 MB와 계산 캐시는 Git 밖에서 보관한다. 공개한 `kobest-sample-metrics.json`은 원본의 선택지 likelihood·문항별 점수만 투영한 파일이다. 원본 hash를 유지하며 이를 원본 보고서로 가장하거나 기존 `collect.py`의 원본 hash 검증을 생략하지 않는다.
