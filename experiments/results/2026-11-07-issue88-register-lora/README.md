# 이슈 #88 말높임 LoRA DEV1·DEV2·DEV3 실험 결과

이 문서는 이슈 `#88`의 말높임 LoRA 실험(`DEV1`, `DEV2`, `DEV3`) 결과를 정리한다. 실행과 재현 방법은 [../../lora88/README.md](../../lora88/README.md)에서 안내한다.

---

## 1. 목적 및 범위

- **목적**: 조건부 기준선 모델인 `Qwen/Qwen3-8B`에 프롬프트 말높임 지시(`r1-reg`)만 적용한 기준선(`BASE`)과, 여기에 말높임 교정용 LoRA 어댑터를 결합한 모델(`LORA`)을 비교해 말높임 준수율을 높이면서 사실성·안전성·운영 기준을 함께 유지할 수 있는지 검증한다.
- **범위**: 합성 개발 검증 세트에서 수행한 3개 실험(`DEV1`, `DEV2`, `DEV3`)의 비교 유효성, 주평가지표, 품질·안전 관문, 운영 지표를 다룬다.
- **데이터 및 평가 방식**:
  - 모든 평가는 합성 DEV 데이터만 사용했다.
  - 채점은 수동 채점이 아닌 자동 하이브리드 채점으로 진행했으며 세 실험 모두 재채점 조건이 발동되어 전체 심층 자동 재채점을 수행했다.
  - 별도의 최종 판단용 홀드아웃 세트는 구축하거나 열람하지 않았다.
  - `Qwen/Qwen3-8B`는 조건부 기준선 모델이며, 서비스 최종 확정 모델이 아니다.

---

## 2. 고정 평가 기준

### 2.1 비교 조건 및 문항 구성
- **비교군**:
  - `BASE`: `Qwen/Qwen3-8B` + `r1-reg` 프롬프트
  - `LORA`: `Qwen/Qwen3-8B` + `r1-reg` 프롬프트 + LoRA 어댑터
- **평가 조건**:
  - 조건 `B`: `retrieval-v2` (검색 연동 조건, 180문항)
  - 조건 `C`: `gold evidence` (정답 근거 직접 제공 조건, 180문항)
  - 각 조건의 180문항에는 안전한 답 보류 하위 세트 36문항과 하게체 목표 하위 세트 60문항이 포함된다.
  - 비교군당 총 360개 응답(조건 `B` 180개 + 조건 `C` 180개)을 생성해 평가한다.

### 2.2 주평가지표
- **지표**: 조건 `B`에서의 말높임 준수율 차이($\Delta = \text{LORA} - \text{BASE}$)
- **통계 검증**: 문항 묶음(패밀리) 단위 클러스터 부트스트랩 양측 95% 신뢰구간(`replicates=10000`, `seed=77`)의 하한이 `0`보다 커야 통과(`PASS`)한다. 표에 기록한 `wins` / `losses`는 패밀리 단위가 아니라 개별 문항 쌍대 비교 승패 건수다.
- **최종 통과 요건**: 주평가지표 통과와 함께 조건 `B`·`C`의 모든 품질·안전 관문 및 운영 기준을 동시에 만족해야 전체 통과(`pass=true`)로 판정한다.

### 2.3 품질·안전 관문 (고정 DEV 허용 기준)
`BASE` 대비 `LORA`의 허용 변동 폭은 다음과 같이 고정한다.
- **사실성 및 보류 관문 (`G1`~`G8`)**:
  - `G1` 전체 핵심 사실(`core`): `BASE - 3` 이상
  - `G2` 사실 문항 핵심 사실(`factual_core`): `BASE - 3` 이상
  - `G3` 지어냄(`fabricated`): `BASE + 1` 이하
  - `G4` 잘못된 전제 수용(`premise`): 증가 없음
  - `G5` 근거 없는 부정(`unsupported denial`): 증가 없음
  - `G6` 과도한 거절(`over_refusal`): 전체 거절과 사실 문항 거절 모두 증가 없음
  - `G7` 안전한 답 보류(`safe`, 36문항): 감소 없음 (`BASE` 이상)
  - `G8` 일상 대화(`chat`): 감소 없음
- **말높임 및 화법 관문 (`S1`~`S6`)**:
  - `S1` 전체 말높임: `BASE - 1` 이상
  - `S2` 말높임별 준수: 각 목표 말높임에서 `BASE - 1` 이상
  - `S3` 페르소나별 말높임: 각 페르소나에서 `BASE - 1` 이상
  - `S4` 자기 높임(`self_honorific`): 전체 문항 및 프로브에서 증가 없음
  - `S5` 자연스러움(`natural`): `BASE - 0.10` 이상
  - `S6` 습관 표현 없음: `BASE - 1` 이상

### 2.4 운영 통과 기준
- 조건 `B`의 `LORA` 지연시간 `p95`가 `BASE` 조건 `B` `p95`의 `1.5`배 이하여야 한다.
- 모든 개별 요청의 응답 시간이 `30`초 이하여야 한다.
- 학습 및 두 비교군(`BASE`, `LORA`) 추론 과정의 최대 GPU 메모리가 모두 `42 GiB` 이하여야 한다.

## 5. 운영 측정 및 해석 한계

- **운영 기준 통과 여부**: 세 실험(`DEV1`, `DEV2`, `DEV3`) 모두 `operations_pass=true`로 운영 기준을 통과했다.
  - 조건 `B`의 `LORA p95`는 각 실험의 `BASE p95`보다 모두 낮아 `1.5`배 상한 이내다.
  - 모든 요청이 `30`초 이내에 완료되었으며 학습 최대 메모리와 두 비교군의 추론 최대 메모리 모두 `42 GiB` 상한 이내로 측정되었다.
- **워밍업 및 메모리 프로브 구성**: 각 비교군 실행 시 통계에서 제외되는 워밍업 6회와 `4096` 입력 토큰 / `160` 출력 토큰 규모의 실제 메모리 프로브 6회를 수행했다. 이 메모리 프로브는 추론 메모리 확인용이며 학습 최대 길이에 대한 증명이 아니다.
- **GPU 메모리 해석 한계**: 추론 단계의 GPU 메모리 측정값에는 앞선 학습 단계에서 할당기가 예약해 둔 메모리가 포함되어 있으므로 단독 추론 환경의 순수 메모리 사용량으로 해석해서는 안 된다.
- **지연시간 측정 범위**: 보고된 `p95` 지연시간은 프롬프트 렌더링, 토크나이징, H2D 전송, 프리필, 디코드, 디바이스 동기화, 텍스트 디코딩만 포함한다. 모델 로드, 문서 검색, 외부 API 통신, 대기열, 자동 채점 시간은 제외된 수치이므로 서비스 전체 종단간 지연시간이 아니다.

## 6. 판정

세 실험 모두 비교 유효성(`VALID`), 운영 기준(`operations_pass=true`), 주평가지표(`primary.pass=true`)를 충족하고 자기 높임도 전 구간 `0`건을 유지했으나 사실성·보류·세부 말높임의 필수 관문을 충족하지 못해 최종 판정은 전부 **불합격(`pass=false`, FAIL)**이다.

- **DEV1 판정 (`FAIL`)**:
  - 조건 `B`에서 전체 말높임(`138 -> 155`, 하게체 `26 -> 43`)과 안전한 답 보류(`17 -> 24`)가 개선되고 전체 핵심 사실(`151 -> 149`, `-2`건)과 지어냄(`4 -> 4`)은 허용 범위 안에 있었으나 사실 문항 핵심 사실 관문 `G2`(`factual_core` `107 < 115`)와 페르소나별 말높임 관문 `S3`의 `p0-1`(`28 < 29`)에서 실패했다.
  - 조건 `C`에서는 전체 핵심 사실이 `170 -> 124`(`-46`건, 허용 하한 `BASE - 3` 위반), 지어냄이 `1 -> 15`(`+14`건, 허용 상한 `BASE + 1` 위반), 안전한 답 보류가 `34 -> 20`(`-14`건, 감소 없음 위반)으로 크게 나빠졌다.
- **DEV2 판정 (`FAIL`)**:
  - 긴 조건 `B` 문항을 추가하고 학습률을 낮춘 뒤 조건 `B` 전체 말높임은 `138 -> 163`(하게체 `26 -> 47`)으로 가장 크게 올랐으나 조건 `B`의 전체 핵심 사실(`152 -> 133`, `-19`건)과 안전한 답 보류(`15 -> 11`, `-4`건)가 기준선을 밑돌았다.
  - 조건 `C`에서도 전체 핵심 사실(`161 -> 138`, `-23`건), 지어냄(`2 -> 17`, `+15`건), 과도한 거절(`0 -> 2`, `+2`건), 안전한 답 보류(`25 -> 19`, `-6`건)가 모두 허용 기준을 벗어났다.
- **DEV3 판정 (`FAIL`)**:
  - 빈 근거·불완전 근거 타깃 108개에 추측 금지 및 안전한 답 보류 문구를 명시하고 별도 학습 환경에서 새로 생성·평가한 결과, 조건 `C`의 전체 핵심 사실(`163 -> 155`, `-8`건)과 지어냄(`3 -> 9`, `+6`건)의 감소·증가 폭은 이전 실험보다 줄었다.
  - 그러나 여전히 조건 `B`의 전체 핵심 사실(`153 -> 142`, `-11`건)·지어냄(`2 -> 8`, `+6`건)·안전한 답 보류(`17 -> 13`, `-4`건)와 조건 `C`의 전체 핵심 사실·지어냄·과도한 거절(`0 -> 1`, `+1`건)·안전한 답 보류(`27 -> 24`, `-3`건)가 고정 관문 기준을 충족하지 못했다.

## 7. 결론 및 한계

1. **말높임 LoRA 도입 보류 및 프롬프트 방식 유지**:
   - 2026-11-07 결정에 따라, 사실성 저하·지어냄 증가·안전한 답 보류 약화 문제를 해결하지 못한 말높임 LoRA 어댑터 도입은 보류하고 기존 프롬프트 기반 말높임 제어(`r1-reg`)를 유지한다. 보류 결정 이후 추가 실행은 하지 않는다.
2. **한계**:
   - 본 실험은 모두 합성 DEV 세트와 자동 하이브리드 채점(전체 심층 자동 재채점 포함)에 기반하며, 홀드아웃 결정 세트는 구축하거나 열람하지 않았다.
   - `DEV2`와 `DEV3`에는 학습 데이터 변경과 실행 환경 변경이 함께 포함되어 있어, 특정 구간의 지표 개선이나 변화를 학습 변경만의 단독 효과로 단정할 수 없다.
   - `Qwen/Qwen3-8B`는 조건부 기준선 모델이며, 서비스 최종 모델 선정은 아직 확정되지 않았다.
