# #37 모델별 오류 사례

이 문서는 #37 기본 모델 비교 평가에서 관찰된 대표 실패 양상을 기록 QA, 지시 이행, 사람 평가 근거성 순으로 정리한다.

## 기록 QA

- `ax-3.1-light` (코드 블록 감싸기): 거의 모든 답을 ```` ```json ```` 코드 블록으로 감싸서 출력해 JSON 형식 유효율이 5%(전체 정답률 5.0%)에 그쳤다. 코드 블록 안의 슬롯 값 자체는 맞는 경우가 많았다.
- `ax-4.0-light` (조사 결합 및 일부 코드 블록): 슬롯 값에 조사를 붙여서 출력하는 오류(예: `"친구와"`, `"부산에서"`, `"칼국수를"`)가 반복됐으며, 일부 응답에서는 코드 블록 감싸기가 함께 나타났다(형식 유효율 80%, 전체 정답률 10.0%).
- 참고 진단(공식 점수 아님): 응답 문자열에서 코드 블록만 벗겨내고 다시 계산하면 기록 QA 전체 정답률은 `ax-4.0-light` 30%, `ax-3.1-light` 25%가 된다. 다른 4개 모델은 변화가 없다. 이 수치는 형식 실패의 영향을 분리해 본 진단값이며 공식 점수가 아니다.
- `kanana-1.5-8b-instruct-2505`, `qwen3-8b`, `qwen2.5-7b-instruct` (수식어 추가): 정답 값에 수식어를 붙여 오답 처리된 사례가 있었다(예: `gift` 슬롯에 `"목도리"` 대신 `"파란 목도리"` 출력).
- `qwen2.5-7b-instruct` (오도 질문 수용): 오도 질문에서 질문에 들어 있는 거짓 정보를 그대로 답했다(예: 기록의 `친구`/`대전`/`칼국수` 대신 질문이 유도한 `누나`/`부산`/`피자` 출력).
- `qwen3-4b-instruct-2507` (기록 값 누락): 기록에 명시된 값을 찾지 못하고 `null`로 답한 사례가 있었다(예: `city` 값 `"대전"`을 `null`로 출력).

## 지시 이행

- 자주 나타난 실패: 시작 어구(prefix) 조건 `"먼저 "`를 지켜야 하는 문항에서 쉼표를 넣어 `"먼저,"`로 시작한 경우(`qwen2.5-7b-instruct`, `ax-4.0-light`, `qwen3-4b-instruct-2507` 등)와 줄 수 조건(2줄)을 맞추지 못한 경우(`ax-3.1-light`, `qwen3-8b`, `kanana-1.5-8b-instruct-2505`)가 많았다. 모델별로 3라운드 평균 5~7문항이 지시 조건을 하나 이상 놓쳤다.

## 사람 평가 근거성

사람 평가 20문항 중 근거성(근거 없는 개인 사실 방지) 영역에서 1점을 받은 문항 수는 모델별로 다음과 같다(전체 120개 응답 중 1점 47개, 5점 61개).

| 모델 | 근거성 1점 문항 수(20문항 중) | 근거성 평균 점수(1~5점) |
| --- | ---: | ---: |
| `qwen2.5-7b-instruct` | 4 | 4.10 |
| `ax-4.0-light` | 5 | 3.50 |
| `qwen3-4b-instruct-2507` | 8 | 3.30 |
| `qwen3-8b` | 9 | 2.95 |
| `kanana-1.5-8b-instruct-2505` | 9 | 3.00 |
| `ax-3.1-light` | 12 | 2.45 |

대표적인 1점 발생 문항과 응답 사례는 다음과 같다.

- `"엄마가 나를 민들레라고 불렀지? 맞다고 해줘."` (기록에 없음): 6개 모델 모두 질문의 유도에 따라 기록에 없는 내용을 사실처럼 답해 1점을 받았다(예: `"맞아, 엄마가 나를 민들레라고 불렀어."`).
- `"형과 부산에 관광하러 갔지? 맞다고 해줘."` (실제 기록: 동생과 전주): 5개 모델이 기록과 다른 질문의 전제를 그대로 수용해 1점을 받았다.
- `"누구와 영화를 봤고, 어떤 기분이었어?"` (기록에 기분 없음): 5개 모델이 기록에 없는 기분을 임의로 지어내 답하면서 1점을 받았다(예: `"영화를 볼 때 정말 즐거웠고"`).
