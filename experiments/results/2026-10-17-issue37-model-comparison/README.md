# 기본 모델 비교 평가 결과 (#37)

학교 GPU 실행일: 2026-10-17. 평가 정리 및 결론 반영일: 2026-10-22.

## 결과 요약

사전 정의한 선정 기준에 따라 6개 후보 모델을 동일 조건에서 비교한 결과 `qwen3-8b`(`Qwen/Qwen3-8B`)를 조건부 추천한다. 1차 기준인 기록 QA 전체 정답률(55.0%)과 지시 전체 충족률(70.0%)에서 `qwen3-4b-instruct-2507`(60.0%, 75.0%)과 두 지표 모두 5%p 이내로 동률을 이뤘고, 2차 기준인 KoBEST 5과제 평균(64.01% 대 59.62%)에서 앞섰다. 사람 평가 4영역 평균은 4.01점으로 기준 모델(`qwen2.5-7b-instruct`, 4.34점)과의 차이가 0.33점이어서 제외 기준(0.5점 이상 하락)에 해당하지 않으나 근거성 영역이 2.95점으로 기준 모델(4.10점)보다 1.15점 낮다. 개인 기록 기반 대화 서비스의 핵심 위험이므로 이후 RAG·파인튜닝 단계에서 근거성을 가장 먼저 측정하는 조건을 붙인다. 서로 다른 평가 축을 하나의 점수로 합치지 않으며, 이번 추천은 서비스 적용 확정이 아니다. 모델별 주요 실패 양상은 [오류 사례](오류사례.md)에 정리했다.

### 사람 평가 진행 방식

- 대상: 20문항(#36 `human.json`) × 6개 모델 = 응답 120개(1라운드 응답).
- 절차: 모델명을 가리고 문항 순서와 문항 안 응답 순서를 무작위로 섞어 블라인드 시트를 구성했다. 사용자 1인이 #33 채점 기준 그대로 네 영역(자연스러움, 지시 준수, 적절성/유용성, 근거 없는 개인 사실 방지)을 1~5점으로 총 480개 채점하고 동일 가중치로 집계했다.
- 기준 확장: 이슈 문구("네 영역을 동일 가중치로")를 따르기 위해 응답마다 네 영역을 모두 채점했다(#33은 문항별 1개 영역, #36은 전체 점수 1개). 이 확장 방식은 사용자와 확인 후 진행했다.
- 무결성 확인: 채점 시트(sha256 `c7249c03…`)와 채점 전 생성한 매핑 파일(sha256 `7f538ba9…`)의 해시를 채점 후 대조했으며, 시트의 응답 원문 120개가 실행 결과와 동일함을 확인했다.

## 선정 기준 적용

평가 실행 전(2026-10-16~17)에 사용자와 확정한 기준과 단계별 적용 결과는 다음과 같다. 사전 기준은 결과 확인 뒤에 바꾸지 않았다.

### 평가 전 확정 기준

- 필수 조건: 상업적 이용 가능 라이선스, 48GB 단일 GPU `bf16` 추론, `transformers` 4.57.1 실행, 본 평가 실행 실패 0%.
- 우선순위:
  1. 기록 QA 전체 정답률·지시 전체 충족률(20문항이라 1문항=5%p이며, 각각 5%p 이내 차이는 동률로 처리)
  2. KoBEST 5과제 평균
  3. 사람 평가 보조 기준: 4영역 평균이 기준 모델보다 0.5점 이상 낮으면 제외 또는 보류
  4. 운영 지표
  5. 위 단계까지 같으면 더 작고 빠른 모델을 우선하고, 그다음 기존 기준 모델을 유지

### 단계별 적용 결과

- 필수 조건: 6개 모델 모두 통과했다.
- 1차(기록 QA·지시 이행): `qwen3-4b-instruct-2507`(60.0% / 75.0%)과 `qwen3-8b`(55.0% / 70.0%)는 두 지표 모두 5%p 이내여서 동률로 분류됐다. `qwen2.5-7b-instruct`(50.0% / 75.0%)는 기록 QA가 `qwen3-4b-instruct-2507`보다 10%p 낮아 동률이 아니며, `ax-4.0-light`, `ax-3.1-light`, `kanana-1.5-8b-instruct-2505`는 기록 QA가 크게 낮아 1차 상위 그룹에 들지 못했다.
- 2차(KoBEST 평균): 1차 동률 모델 중 `qwen3-8b`(64.01%)가 `qwen3-4b-instruct-2507`(59.62%)보다 높아 선택됐다.
- 3차(사람 평가 보조 조건): `qwen3-8b`의 사람 평가 4영역 평균은 4.01점으로 기준 모델(4.34점)보다 0.33점 낮아 제외 기준(0.5점 미만 차이)에 걸리지 않았다.
- 결론(2026-10-22 사용자 선택): `qwen3-8b`를 조건부 추천한다. 단, 이번 추천은 서비스 적용 확정이 아니며 아래 추가 검증을 전제로 한다.

## 추가 검증 사항과 한계

### 추가 검증 사항

- 근거성 집중 점검: `qwen3-8b`의 사람 평가 근거성 점수는 2.95점으로 기준 모델(4.10점)보다 1.15점 낮다. 개인 기록 기반 대화 서비스의 핵심 위험이므로 RAG·파인튜닝 단계에서 근거성을 가장 먼저 측정한다. 세부 실패 문항은 [오류 사례](오류사례.md)에서 다룬다.
- KoBEST 점수 차이: `qwen3-8b`(64.01%)와 `qwen3-4b-instruct-2507`(59.62%) 모두 KoBEST 평균이 기준 모델(67.54%)보다 낮다. `qwen3-8b`는 다른 회사 모델 카드에 실린 교차평가 수치(약 79~80)와도 다르다. 이번 KoBEST는 chat template 없는 0-shot loglikelihood 방식으로 실행했으며 구체적인 원인은 미확인 상태다.
- 추론 속도: `qwen3-8b`의 기록 QA 생성 속도(24.8 tok/s)는 기준 모델(32.4 tok/s)보다 약 25% 낮다.

### 평가 한계

- 사람 평가 표본과 분포: 평가자 1인이 20문항을 채점했으므로 영역 평균 0.2~0.3점 차이는 문항 몇 개 차이에 해당한다. 자연스러움 영역은 120개 중 117개가 5점이어서 천장 효과가 나타났고(변별력 낮음), 근거성은 1점 47개·5점 61개로 양 끝에 몰렸다.
- 기계 평가 표본: 기록 QA와 지시 이행 모두 각 20문항이어서 1문항 차이가 5%p로 반영된다.
- 대용량 원본 보관: KoBEST 원본 결과(`result-*.json`, 모델당 약 9.9MB)와 likelihood cache는 Git에 넣지 않고 학교 서버와 로컬 개인 보관소에 두었다. 각 KoBEST run의 `report.json` 안 `result_sha256`이 원본 파일을 가리킨다.
- 범위 제외: 파인튜닝, RAG, 서비스 연동은 이번 평가 범위 밖이다.

## 파일 구성과 재확인

결과 폴더(`experiments/results/2026-10-17-issue37-model-comparison/`)의 구성은 다음과 같다.

- `downloaded-results-001/`: 18개 생성 run(`metadata.json`, `cases.json`, `events.jsonl`)과 6개 KoBEST run(`identity.json`, `events.jsonl`, `report.json`). 원본 대용량 결과·캐시는 제외했으며 개인 경로 문자열 검사 결과 0건이다.
- `scoring-001/`: `report.py` 실행 결과(모델×과제 18개).
- `human-blind-001/`: 채점 시트(사용자 점수), 채점 안내, 매핑 파일, 집계 결과.
- `comparison.json`: 모델별 지표와 조건부 추천 내역.
- `published-files.json`: 공개 파일 sha256 목록.
- `verify.py`: 공개 파일 해시, 기계 재채점, KoBEST 보고서, 맹검 집계를 재계산해 `comparison.json`과 대조하는 스크립트.

저장소 루트에서 다음 명령으로 결과를 재확인한다(실행 결과 `PASS` 확인).

```bash

```
