# Persona Guard 실험 및 런타임 유틸리티

## 목적

페르소나 자신을 제3자나 질문 대상으로 지칭하는 응답 오류를 줄이기 위해, 프롬프트 보조 템플릿과 출력 사후검사 유틸리티 및 실험 구성을 정리합니다.

## 동작 및 API (`ai/src/persona_guard.py`)

외부 의존성 없이 Python 표준 라이브러리만으로 동작합니다.

- `PersonaIdentity(relationship_aliases, name_aliases, register)`에는 호출자가 관계 별칭, 이름 별칭, 말투를 명시적으로 전달합니다.
- `check_reply(text, persona)`는 전달된 별칭과 일부 조사·문장 패턴을 검사해 `GuardResult(text, matched)`를 반환합니다. `matched`는 탐지된 구절이며, 탐지되지 않으면 `None`입니다.
- 패턴이 탐지되면 말투에 맞는 짧은 불확실성 문장으로 답변 전체를 교체합니다. 탐지되지 않으면 입력을 그대로 돌려줍니다.
- `PERSONA_RULES`는 기존 프롬프트에 덧붙일 수 있는 규칙 템플릿입니다. 기억 범위 밖의 질문에는 이미 제공된 기억으로 답하거나 짧게 기억이 나지 않는다고 말하고, 없는 기억을 만들거나 불필요한 질문을 먼저 하지 않도록 안내합니다.

런타임 가드는 생존·사망 여부에 같은 규칙을 적용하며 생사를 추론하지 않습니다. 입력 자료에는 생사 상태 필드가 없습니다.

## 테스트 및 리플레이 검증

### 단위 테스트

저장소 루트에서 실행합니다.

```bash
python3 -B -m unittest discover -s ai/tests -v
```

전체 14개 테스트가 통과했습니다. 별도 고정 QA 10건도 통과했습니다.

### 합성 고정 픽스처 리플레이 (기본 실행)

모델을 로드하거나 호출하지 않고 합성 사례만 검사합니다.

```bash
python3 -B experiments/persona_guard/replay.py
```

고정 사례 51건 중 24건은 교체, 27건은 통과했습니다. 기대 결과 불일치와 독립 사후검사 위반은 각각 0건입니다. 요약과 전체 결과는 `experiments/persona_guard/results.json`에 기록되어 있습니다.

### 기존 생성물 144건 리플레이

모델을 호출하지 않고 합성 코퍼스와 이미 생성된 `generations.jsonl`을 읽어 사후검사를 수행합니다. 코퍼스와 생성물은 모두 합성이어야 하며 A/B/C 구성을 모두 갖춰야 합니다. 결과는 stdout에 JSON으로 출력됩니다.

```bash
python3 -B experiments/persona_guard/replay.py \
  --corpus /path/to/corpus-heldout.json \
  --generations experiments/rag/results/heldout/generation/r1/generations.jsonl
```

144건 중 2건(`p5 / ho-p5-08`의 A와 B)을 탐지했고, 나머지 142건은 바이트 단위로 동일하게 유지했습니다.

## 한계 및 통합 상태

### 인식 및 교체 방식의 한계

인식은 호출자가 전달한 별칭과 일부 조사·문장 패턴에 한정됩니다. 일반적인 한국어 의미를 판별하지 않으므로 미탐이나 오탐이 발생할 수 있습니다. 탐지하면 답변 전체를 교체해, 원래 답변의 유효한 정보도 함께 사라질 수 있습니다.

### 현재 통합 상태와 범위

`PERSONA_RULES`는 기본 프롬프트에 설치되지 않았고 실제 모델 출력 품질도 검증하지 않았습니다. 서비스·계약·API 변경은 없습니다. 런타임에서 사용하려면 호출자가 구분된 이름·관계 별칭과 말투를 명시적으로 전달해야 합니다. 정보 출처, #78에서 프롬프트 규칙과 출력 가드를 적용할 위치, 공통 불확실성 대체 문구는 후속 논의 제안이며 합의된 사항이 아닙니다. #43/#44 런타임 변경, #15/#29 계약 변경, #71 일반 사후검사는 범위에서 제외됩니다.
