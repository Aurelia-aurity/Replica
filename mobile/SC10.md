# SC-10 음성 대화

현재 브랜치에서 화면 기획서 12쪽과 제공된 앱 ↔ 백엔드 API 명세(2026-10-13)를 참고해 구현했습니다. 변경은 `mobile/` 내부로 제한했습니다.

## 화면과 동작

- 홈 ‘음성으로 대화’ 또는 이력에서 선택한 음성 대화로 진입합니다. 대화방 안에서 텍스트·음성 방식을 전환하는 기능은 제공하지 않습니다.
- 말하기 버튼을 탭하면 녹음을 시작하고, 다시 탭하면 중지한 녹음을 전송합니다. 녹음 중에는 중지 모양·경과 시간·실제 입력 진폭을 표시하며 취소할 수 있습니다. 최대 1분에서 자동 중지·전송합니다.
- 마이크 권한 거부 시 필요한 이유와 ‘설정 열기’를 표시합니다. Android/iOS는 앱 설정을 열고, 웹·그 외 플랫폼은 기기/사이트 권한 안내를 제공합니다. 웹 녹음에는 브라우저가 허용하는 보안 연결이 필요합니다.
- 녹음 → 인식 → 응답 생성 → 음성 합성의 상태와 서버가 반환한 단계별 시간을 표시합니다. `/chat/voice`는 한 번에 결과를 주는 API라서 처리 중에는 인식·응답·합성이 진행 중인 묶음으로 표시합니다. 서버가 주지 않는 실시간 단계 전환은 추측하지 않습니다.
- 인식된 질문, 답변 글, AI 생성 배지, 합성 음성 고지를 표시합니다. 근거 정보가 있으면 SC-09의 근거 시트를 재사용합니다.
- 첫 재생 전에 ‘합성한 목소리예요’ 안내를 확인받습니다. 자동 재생하지 않으며 재생·일시정지·이어서 재생·위치 이동과 경과 시간을 제공합니다. WAV의 PCM 진폭은 실제 샘플에서 그리며, 그 외 형식은 진행 표시를 사용합니다.
- TTS가 실패해도 질문·답변 글과 대화 이력을 유지합니다. ‘음성 다시 시도’는 해당 턴의 TTS만 재요청하며 음성 질문이나 AI 답변을 다시 만들지 않습니다.
- 받은 음성과 TTS 재시도 결과는 같은 음성 화면에서 다시 재생할 때 재사용합니다. 전송·합성 중에는 중복 조작을 막습니다. 다른 방식으로 대화하려면 홈이나 대화 이력에서 새 대화를 만듭니다.

## 녹음과 요청

`record`의 PCM 스트림을 메모리에서 모아 WAV 헤더를 붙입니다. 기본 요청은 16 kHz·16비트·모노이며, 장치가 조정한 실제 샘플레이트·채널 수가 있으면 헤더에 반영합니다. 녹음 원본 파일은 로컬에 생성하지 않습니다. 빈 녹음·아주 짧은 녹음·무음과 파일 크기 한도를 검사합니다. 녹음 시간 제한과 별개로 API 파일 한도는 25MB입니다.

| 동작 | 규격 |
| --- | --- |
| 음성 질문 | 인증된 `POST /chat/voice`, `multipart/form-data` |
| 폼 | 기존 `session_id`, 앱 생성 UUID `turn_id`, WAV `file` |
| 정상 응답 | `transcript`, `answer`, `is_ai_generated`, `turn_id`, `finish_reason`, `model_name`, `timings`, TTS 상태·음성 |
| 음성만 재시도 | 인증된 `POST /chat/turns/{turn_id}/tts` |

매 요청마다 현재 인증 헤더를 구하며 사용자 ID나 텍스트 이력을 폼에 추가하지 않습니다. 같은 녹음의 수동 재전송에는 같은 턴 ID·바이트를 유지하고, 새 녹음은 새 턴 ID를 사용합니다. 오래된 요청이 나중에 완료돼도 새 녹음의 재시도 ID를 지우지 않습니다. 자동 네트워크 재시도는 하지 않습니다.

30초 타임아웃·오류의 단계·재시도 가능 여부를 처리합니다. STT 실패와 무음은 다시 말하기를 안내하고, 응답 대기 중에는 중복 녹음·전송을 막습니다. 화면을 나간 뒤 도착한 응답은 화면이나 재생을 시작하지 않습니다. 로그아웃·계정 전환 후의 응답과 401은 기존 로그인 세대 검사를 통과해야 합니다.

화면 종료·앱 비활성화 시 녹음·재생 자원을 정리합니다. 녹음 취소 시 메모리 버퍼를 버립니다. 합성 음성의 플랫폼별 임시 파일 정리는 SC-09 플레이어를 재사용합니다.

## 기본 실행과 연동 범위

앱 기본 실행은 기존 미리보기 인증을 유지합니다. 미리보기에서는 실제 마이크 권한을 요청하거나 음성을 서버에 전송하지 않으며, 말하기 버튼으로 합성 질문·답변·음성 이력 저장 흐름을 확인합니다. 음성 합성·출력은 제공하지 않는다고 표시합니다.

실제 인증 서비스를 주입한 경로는 `BACKEND_BASE_URL`의 음성 API를 호출하도록 구현했습니다. 실제 백엔드 및 실제 기기의 마이크·STT·TTS·오디오 출력 통합 검증은 별도로 필요합니다. 기존 명세에 없는 근거 조각·근거 없음 필드는 임의로 추가하지 않았습니다. 이력 API에는 기존 음성 파일 다운로드 규격이 없어, 다시 연 대화의 음성 재생 한계는 [SC09.md](SC09.md)를 따릅니다.

Android 마이크 권한, iOS/macOS 사용 목적 문구, macOS 오디오 입력 권한을 추가했습니다. `permission_handler`는 저장소 Android SDK와 맞는 12.0.1로 고정했으며, 마이크 권한 요청 자체는 `record`가 수행합니다. 권한 플러그인은 설정 화면 이동에 사용합니다. 구현 참고: [record 공식 문서](https://pub.dev/packages/record), [permission_handler 12.0.1](https://pub.dev/packages/permission_handler/versions/12.0.1).

## 검증

2026-10-28 기준 최종 전체 Flutter 테스트 **95개**와 정적 분석이 통과했습니다. SC-10 추가 테스트는 19개입니다. 웹 빌드와 녹음·권한 플러그인을 포함한 Android 디버그 APK 빌드도 성공했습니다. 실제 기기의 마이크·음성 출력·실제 서버 연결은 미검증이며, iOS/macOS 빌드는 이 Windows 환경에서 수행하지 않았습니다.

추가 테스트는 WAV 헤더, multipart 파일·인증·대화방 ID, 동일 녹음 재전송 ID와 오래된 응답 경합, 권한 거부·무음·취소·1분 제한, 전송 실패·30초 타임아웃, TTS 부분 실패와 별도 재시도, 재생·일시정지·탐색, 방식 전환 버튼 없음, 늦은 응답·계정 전환과 320×568 레이아웃을 포함합니다. 테스트는 가짜 녹음기·플레이어·HTTP 응답을 사용하며 실제 마이크를 켜지 않습니다.

`docs/screenshots/sc10/`에는 390×844 논리 크기·Windows 한글 글꼴·합성 데이터로 렌더링한 녹음 전·녹음 중·답변·재생·TTS 실패·권한 안내 화면이 있습니다. 실제 기기 캡처가 아닙니다.
