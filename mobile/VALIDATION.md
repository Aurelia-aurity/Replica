### 사용자가 직접 확인할 흐름

1. 홈에서 텍스트 또는 음성 대화 버튼을 누릅니다.
2. 이해 확인 전 대화 시작이 비활성이고, 배경 탭·드래그·뒤로 버튼으로 시트를 닫을 수 없는지 확인합니다.
3. ‘닫기’는 홈으로 돌아가며, 이해 확인 후 ‘대화 시작’은 선택한 화면을 여는지 확인합니다.
4. 텍스트를 주고받은 뒤 마이크 → 음성 화면 → 키보드 → 텍스트 화면에서 대화와 입력값이 유지되는지 확인합니다.
5. 뒤로 홈에 돌아가 새 대화를 열면 다시 안내하고 이전 세션을 보관하지 않는지 확인합니다.
6. 작은 화면·가로 화면·큰 글자 설정 및 키보드가 열린 상태에서 화면과 입력 버튼을 확인합니다.
7. 음성 버튼에서 미구현 안내를 표시하며 마이크 권한을 요청하거나 녹음하지 않는지 확인합니다.

## PR 설명에 포함할 내용

mobile/에 Flutter 프로젝트와 SC-09 기획서 기반의 대화 화면을 구성했다. 고정 AI 표시 띠, 사용자·AI 말풍선, 응답별 AI 생성 배지, 듣기 안내, 점 세 개 로딩 표시와 음성·텍스트 입력 바를 반영했다. 메시지 입력·전송, 실패 시 재시도·수정과 환경별 백엔드 URL 설정을 추가했다.

API 명세가 아직 없어 실제 서버 통신은 구현하지 않았으며 화면에 데모 모드를 표시한다. 근거 기록과 근거 없음 응답은 고도화 2 범위로 남겼다. 음성 대화 및 TTS 재생은 준비 상태를 안내한다.

검증: 이전 SC-09 구현에서는 flutter analyze와 테스트 10개가 통과했으나, 홈·AI 안내·음성 화면을 추가한 현재 변경은 사용자 요청으로 미검증입니다. Android·iOS 실제 실행 및 빌드와 화면 육안 확인은 미검증. 코드·문서 변경은 mobile/에만 한정했다.
