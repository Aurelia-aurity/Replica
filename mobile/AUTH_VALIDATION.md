## 2026-10-15 인증 계약·401 더미 처리

- `SignUpRequest`에 동의 정보를 포함하고 `SignUpResult`로 로그인 완료·이메일 인증 필요·로그인 필요를 구분했습니다.
- 인증 오류 종류와 화면 안내를 연결하고 기존 미연결 SDK 어댑터의 결과·오류 타입도 맞췄습니다.
- 프론트엔드 `BackendService`/`SessionChatService`를 통해 현재 세션의 401만 로그인 상태를 해제합니다. 네트워크 오류·403은 상태를 유지하고 어떤 요청도 자동 재전송하지 않습니다.
- 중복 401, 같은 계정으로 재로그인한 뒤 이전 401, 다른 계정으로 바꾼 뒤 이전 401·성공 응답, 대화·초안·뒤로 이동 제거를 검사했습니다.
- 기존 SDK 갱신 이벤트가 401로 해제된 UI 세션을 재개하지 않는 경우도 모의 HTTP로 검사했습니다.

- `flutter test --no-pub`: **48개 모두 통과** (기존 31개와 계약·401 검사 17개).

- 실제 인증 서버·RLS·기기 실행 검증은 남아 있습니다. 상세 계약과 미정 항목은 [AUTH_CONTRACT.md](AUTH_CONTRACT.md)를 참고하세요.
