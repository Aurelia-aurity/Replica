# 이슈 #10: 전사 확인·수정·확정

첨부된 SC-05·SC-06과 2026-10-13 앱↔백엔드 API 초안을 참고했습니다. 수정은 `mobile/`에 한정합니다. 기본 실행은 합성 전사문을 사용하는 미리보기이며 실제 STT·파일 원본·개인화 처리가 아닙니다.

## 화면과 동작

기록 목록의 항목을 탭하면 전사 확인으로 이동합니다. 초안은 수정할 수 있고, 전사 중·실패·결과 없음·조회 실패를 구분합니다. ‘확정하기’는 전사 완료된 비어 있지 않은 초안에서만 활성화됩니다. 저장 중에는 수정·중복 제출·뒤로가기를 막습니다.

수정 입력은 로그인 세션의 메모리 초안에 즉시 보관합니다. 뒤로 나갔다 다시 열어도 입력이 유지되고, 로그아웃·계정 변경 시 폐기됩니다. ‘나중에’는 변경이 있으면 초안 저장 후 목록으로 돌아갑니다. 저장 실패 시 화면과 입력을 유지합니다. 앱 재시작을 넘는 로컬 영구 저장은 구현하지 않았습니다.

‘확정하기’는 변경 내용을 먼저 저장하고 최신 버전으로 확정합니다. 수정 저장은 `expected_updated_at`을 보내 충돌을 검사하며 409에서는 입력을 유지하고 최신 내용을 재조회하게 합니다. 확정 응답 유실 후 수동 재시도는 먼저 버전 상태를 조회해 이미 확정된 버전을 재사용합니다. 확정본은 이 화면에서 직접 수정하지 않습니다.

확정한 기록은 SC-06의 상세 구성을 참고해 파일명·종류·올린 날·확정일·전사문·개인화 상태를 읽기 전용으로 표시합니다. 삭제 확인·진행·부분 실패 확인은 이어 구현한 [이슈 #11 문서](SC06.md)를 따릅니다.

## 초안 API 연결

- `GET /records/{id}`와 `GET /records/{id}/text-versions`: 가장 최신 revision의 초안 또는 확정본 조회.
- `PATCH /text-versions/{id}`: 수정 내용과 `expected_updated_at` 전달.
- `POST /text-versions/{id}/confirm`: 확정본과 확정일 확인 후 성공 처리.
- `GET /personas/{persona_id}/style-profile`: 확정 후 상태 재조회. 프로필 조회 실패는 이미 확인된 확정 전사문을 숨기지 않습니다. 401·세션 변경은 기존 보호 로직을 따릅니다.

요청마다 현재 인증 헤더와 기존 30초 제한을 사용합니다. 기존 세션 조정자가 지연 응답·401을 처리합니다. 실제 서버 연결 검증은 하지 않았습니다.

## 명세에 없는 항목

- 원본 음성 조회 URL과 타임스탬프·구간·신뢰도 필드가 없습니다. 따라서 SC-05의 재생·구간 이동·단어 강조는 비활성 안내로 구분하고 전사문 전체를 편집합니다. 임의 시간이나 확률을 만들지 않습니다.
- 전사 재시도 API가 없습니다. 서비스가 지원할 때만 재시도 버튼을 활성화하며, 기본 미리보기의 재시도는 합성 상태만 바꿉니다.
- 말투 프로필의 `null`은 없음·생성 중·stale을 구분하지 못하고, `ready`도 해당 기록의 색인·반영 완료를 증명하지 못합니다. 실제 어댑터는 ‘확정됨’과 ‘반영 상태 확인 필요’를 구분합니다. 미리보기에서만 명시적으로 합성 ‘반영됨’을 보여줍니다. 처리 중·실패 상태를 확정하려면 서버의 추가 계약이 필요합니다.
- 새 revision 생성 API는 명세에 있으나 확정본 재편집 UX는 이번 화면에 추가하지 않았습니다.

## 검증

2026-10-30: 전체 Flutter 테스트 76개 통과, 최종 정적 분석 문제 없음, 웹 빌드 성공. 전사 관련 추가 테스트를 수행하고 합성 전사 확인·상세 화면을 렌더링해 확인했습니다. 화면 이미지는 `docs/screenshots/issue9/transcript-review.png`, `record-detail.png`이며 실제 기기 캡처가 아닙니다.

모의 서비스·HTTP 응답으로 수정 보관, 충돌·확정 실패 후 재시도, 중복 제출, 화면 폐기 후 지연 응답, 전사 중/빈 입력 확정 차단, 목록↔수정↔상세 진입, 작은 화면과 API 요청 형식을 검사합니다. 기존 기록·인증 테스트도 함께 실행합니다. 실제 기기의 원본 오디오 재생·STT·서버 반영 검증은 별도입니다.
