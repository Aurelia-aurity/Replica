# 이슈 #11: 기록·계정 삭제 확인과 결과

SC-06 화면기획서와 2026-10-13 앱↔백엔드 명세 초안을 기준으로 `mobile/` 안에 구현했습니다. 실제 자료나 원격 계정을 삭제하며 검증하지 않았습니다.

## 기록 삭제

전사 확인 화면의 상단 삭제 아이콘 또는 확정 기록 상세 하단의 ‘이 기록 삭제’에서 확인 시트를 엽니다. 원본·전사문·검색 색인·프로필 반영분을 함께 지우는 범위와 되돌릴 수 없다는 안내를 표시합니다. 요청 전 ‘취소’는 API를 호출하지 않습니다.

`DELETE /records/{record_id}`의 202 응답은 삭제 작업 접수로 처리합니다. 작업 ID를 유지하고 `GET /deletion-jobs/{job_id}`로 조회합니다. `status=completed`와 빈 `remaining_steps`를 모두 확인한 경우에만 완료로 표시합니다. ‘completed’인데 남은 항목이 있거나, 조회가 실패하거나, 기록이 목록에서 사라진 것만으로는 완료 처리하지 않습니다.

요청 중에는 중복 조작·시트 닫기·뒤로가기를 막습니다. 접수 후 ‘닫기’는 삭제 취소가 아니며, 기록 목록에 삭제 요청 카드가 남아 상태를 다시 확인할 수 있습니다. 실패한 부분의 남은 항목을 한국어로 표시합니다. 조회·재시도 응답은 기존 작업 ID와 삭제 대상이 일치해야 받아들입니다.

목록 새로고침에서는 `GET /deletion-jobs?limit=100&offset=...`를 이어 읽어 이전 작업을 복원합니다. 작업의 원본 경로나 manifest는 표시하지 않습니다. 삭제 접수된 기록은 숨기고, 완료된 기록의 메모리 초안은 제거합니다. 확인 시트에 들어갔다 취소한 것만으로 목록에서 숨기지 않습니다.

## 계정 삭제

홈의 계정 버튼 → ‘계정 삭제’에서 모든 기록·대화·계정 정보의 삭제 범위를 확인합니다. 완료 확인 후 계정별 화면·전사 임시 초안·삭제 상태를 폐기하고 로그인 화면으로 돌아갑니다. 완료 콜백은 요청을 시작한 로그인 세대에 묶이므로 이전 세션의 결과가 새 로그인을 해제할 수 없습니다.

계정 삭제 요청·응답은 명세에서 미정입니다. **실제 API 어댑터에서는 계정 삭제 요청을 비활성화**하고 임의의 `DELETE /account`를 호출하지 않습니다. 향후 확정된 계약의 서비스 구현을 주입해야 합니다. 이미 서버가 생성한 계정 삭제 작업이 조회되면 기존 작업의 상태 확인은 가능합니다.

## 재시도·미리보기

명세에는 실패한 삭제 worker를 재개하는 API가 없습니다. 실제 어댑터는 실패 시 ‘상태 다시 확인’을 제공하고, 삭제 작업 재시작 경로를 추정하지 않습니다. 서비스가 재시도 기능을 명시적으로 지원하는 경우에만 같은 작업 ID의 재시도를 제공합니다. 새 작업을 만들어 부분 실패를 감추지 않습니다.

기본 미리보기는 합성 기록·메모리 초안만 삭제하며 실제 파일·계정에는 영향을 주지 않습니다. 삭제 요청에서 pending 작업을 만들고, 사용자가 상태를 확인하면 합성 완료 결과를 돌려줍니다. 계정 삭제도 미리보기 세션만 종료합니다. 실제 삭제 worker·Storage·검색 색인·프로필·Auth 삭제 완료 검증은 백엔드 담당과의 통합 단계에 남아 있습니다.

진행 상태 조회는 사용자가 요청하는 방식이며 자동 polling이나 백그라운드 알림은 추가하지 않았습니다. 이전 로그인 요청의 지연 응답과 401은 기존 세션 조정자가 처리합니다. 권한 없음/404/원시 서버 오류는 자료의 존재나 내부 경로를 노출하지 않는 안내로 표시합니다.

## 검증

2026-10-30: 전체 테스트 87개 통과, 최종 정적 분석 문제 없음. 하단 버튼 배치 수정 후 삭제·화면 테스트 15개를 추가 실행해 통과했으며, 합성 이미지에서 삭제 확인·부분 실패와 고정 액션 버튼을 확인했습니다. 캡처는 `docs/screenshots/issue9/record-delete-confirm.png`, `record-delete-partial-failure.png`입니다.

`test/record_deletion_test.dart`에서 완료 판정, 중복 요청 방지, 취소 무요청, 부분 실패·같은 작업 재시도, 지연 응답, 목록 복구·초안 정리, 계정 삭제 전후 로그인 상태, 작은 화면, 실제 어댑터의 경로·인증과 미합의 요청 차단을 모의 응답으로 검사합니다. 실제 삭제는 실행하지 않습니다.
