# 기록 화면 미리보기

SC-03~SC-06 기획서를 참고해 390×844 논리 크기에서 Flutter 위젯을 렌더링한 이미지입니다. 실제 기기 캡처가 아닙니다. 합성 파일명·시간·길이·상태를 사용하며 실제 자료 업로드나 개인화 처리를 검증한 화면이 아닙니다.

2026-11-13, 기준 커밋 `5f8385b`에서 아래 명령으로 전체를 다시 렌더링했습니다. `record-list.png`는 이전 캡처와 같은 결과가 나와 바뀌지 않았습니다.

- `record-list.png`: 전체·유형 필터, 행 오른쪽의 상태 배지(반영됨·확인 필요·전사 중)와 전사 실패 항목의 다시 시도, 확정 자료 안내, 하단 탭.
- `record-upload.png`: 기록 종류 카드, 파일 카드·변경, 동의 카드, 하단 고정 올리기와 취소. 합성 파일이 일반 텍스트라 화자 선택 단계는 나타나지 않습니다.
- `transcript-review.png`: SC-05 전사 확인. 미리보기 재생 바(소리 없이 진행 시간만 표시), 확정 안내, 번호가 붙은 전사 구간과 ‘전체 텍스트로 수정’, 하단 나중에·확정하기. 합성 전사에 구간 시간이 없어 구간 이동 불가 안내가 표시됩니다.
- `record-detail.png`: SC-06 확정 기록 상세. 재생 바, 종류·올린 날·상태·확정일, 전사문 전체 보기, 반영 상태와 새로고침, 삭제 진입 버튼.
- `record-delete-confirm.png`, `record-delete-partial-failure.png`: 이슈 #11의 삭제 확인 시트와 단계별 결과(검색 색인 남음)·다시 시도. 모의 서비스가 반환한 상태이며 실제 파일 삭제 결과가 아닙니다.

캡처의 ‘반영됨’은 명시적으로 주입한 합성 상태입니다. 현재 ‘반영됨’은 텍스트 업로드 또는 음성 전사문 확정의 서버 저장 성공을 뜻하는 임시 기준이며, 실제 개인화·색인 완료를 증명하지 않습니다.

Windows에서 캡처 재생성: `flutter test --no-pub test/records_design_test.dart --dart-define=RECORD_UI_CAPTURES=true`. 캡처 모드는 Windows 맑은 고딕과 `C:/flutter`의 Material Icons를 로드합니다. 일반 테스트는 해당 파일에 의존하지 않습니다.
